# 导诊表（问题类型 → 模块路由）

> Agent 检索层的编辑型派生物：内容汇总自各模块 README 的分区判据与 `skill/skill-1-检索路由与歧义消解.md` 第五步路由表，模块职责调整时同步本表。本表只做路由，不承载知识正文；与模块 README 冲突时以 README 为准。

## 使用顺序

1. 先查 `消歧字典.json` 完成俗称归一（流程见 skill-1，对所有检索类问题必走）。
2. 按下方路由表定位模块与入口文件。
3. 用 `标题清单.md` 定位到小节，读 `docs/` 正文。
4. 组合类问题按真源层级取用：组合注册表 > 组合总览 > 组合深稿 > 高效率散件/释义；命名与成员争议以注册表为裁决真源。

## 边界

- 运行时输入（用户 box、需求、排班报告）不进入知识库，按提问上下文处理。
- `index/`、`skill/`、`agent/`、`scripts/` 属行为与检索支撑层，不作为回答依据。
