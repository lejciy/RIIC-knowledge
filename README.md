# RIIC-knowledge

> 明日方舟「罗德岛基建」（RIIC）知识库：110 篇结构化正文，配套检索索引、场景问答手册与系统提示词，面向 RAG／LLM Agent 直接接入。

## 仓库是什么

这是明日方舟基建玩法的玩家知识库。它把基建拆成可检索的结构化文档——机制公式、设施面板、干员技能原文、组合方案、排班操作、布局选择与数值核算——每篇正文都带 front matter 元数据，并配一份由脚本生成的检索索引，因此既适合人读，也能直接作为 RAG 语料喂给 LLM。

与一般攻略帖的区别在于**每个数字都有出处**：产出数值、效率与换算关系集中在《产出常数表》注册，正文只引用不复制；工具（riic.autos）能算的排班表不重复生成，只解释机制与取舍。所有结论按「文件 · 小节」标注来源，可逐条回溯。

## 有什么功能

**能回答的问题**

| 类型 | 例子 |
|---|---|
| 机制解释 | 效率怎么叠加、订单分布怎么算、心情怎么消耗、裁缝技能怎么改订单 |
| 干员与组合 | 龙舌兰组／巫恋组怎么用、缺某个干员怎么降级、两组合同场景怎么选 |
| 布局与无人机 | 243／252／342／153／333 怎么选、无人机优先投哪条产线 |
| 排班与换班 | 12/12/12 怎么排、错班轮换与队列轮换的区别、MAA 怎么执行 |
| 数值核算 | 日产月产折算、折玉折抽、回本周期、报表产值分档诊断 |
| 练卡取舍 | 为基建练谁、先练谁、多久回本 |

**仓库组成**

- `docs/` —— 110 篇正文，分 7 个模块：基础设定／干员技能／组合库／排班算法／换班操作／专家经验／基建布局
- `index/` —— 检索索引层：`消歧字典.json`（俗称归一）、`导诊表.md`（问题类型到模块的路由）、`标题清单.md`（文件与小节索引）
- `skill/` —— 8 条场景问答 skill：把「链路长、单次检索易断链」的问题形态固化成必走步骤（检索路由、产出核算、缺员替代、组合对比、报表对账、边界转介、练卡取舍、产值诊断）
- `agent/SYSTEM_PROMPT.md` —— 系统提示词：数值红线、语言禁忌与回答方式
- `tests/问答测试样例.md` —— 12 题回归用例：题目＋作答路径＋标准答案，用于检验接入效果
- `scripts/` —— 索引生成脚本（`build-agent-index.mjs`，从 `docs/` 重建 `index/`）

## 怎么用

### 接入 RAG

1. 先读 `AGENTS.md` —— 语料范围与建议读取顺序，是本仓库的 Agent 接入入口
2. 语料为 `docs/**/*.md`；`index/`、`skill/`、`agent/` 属检索与行为支撑层，作流程依据而非事实来源
3. 检索前用 `index/消歧字典.json` 把玩家俗称归一为库内规范名（如「巫恋组」→「龙舌兰组」、「裁缝β」→「裁缝·β」）；子串同名对（如「临光」与「耀骑士临光」）按字典 `resolution` 字段处理
4. 场景类问题挂载 `skill/` 对应条目，多条叠加时执行顺序为 skill-1 →（2/3/4/5/7/8 按需）→ skill-6 兜底
5. 用 `agent/SYSTEM_PROMPT.md` 作为系统提示词
6. 作答附出处（文件与小节）

### 重建索引

正文改动后运行：

```bash
node scripts/build-agent-index.mjs
```

脚本从 `docs/` 正文生成 `index/消歧字典.json` 与 `index/标题清单.md`，不带时间戳、重复运行结果一致。索引是派生物，与正文冲突时以正文为准。

## 语料边界

- `docs/**/*.md` 是知识正文；各模块 `README.md` 只作导航，不承载知识正文
- `docs/2-干员技能/` 根目录快照为 RIIC-Web 数据派生的只读产物，请勿手改；`释义/` 为人工维护区
- `index/` 为脚本派生物，请勿手改
- 产出与回本核算按 `skill/skill-2-产出核算链.md` 的取数流程执行；完整排班表与方案级计算请用 riic.autos 生成，本库不独立编方案
- 工具操作类问题（MAA 配置、排班表导入等）只答知识库已载明的部分
