# 知识库问答技能（skill/）

> 知识库级的场景化问答 skill，以 prompt 形式编写，每条独立可用。定位与 `agent/SYSTEM_PROMPT.md` 同层：SYSTEM_PROMPT 是总则（数值边界、语言禁忌、回答方式），本目录是具体问题形态的执行流程；两者冲突时以 SYSTEM_PROMPT 为准。本目录属于 agent 行为层，与 `agent/`、`index/` 一样不入 RAG 语料；目录名不带编号——模块编号体系只覆盖 `docs/` 下的 7 个内容模块，本目录在其外并列。

## 背书来源

各 skill 由高频提问逐类实测知识库回答路径后提炼：链路完整但环节多、单次检索容易断链的问题形态，固化为下面的必走步骤；知识库单点即可答好的问题不设 skill。

## 使用方式

- 作为 RAG 系统提示词的场景扩展按需注入：识别问题形态后挂载对应 skill，skill-1 对所有检索类问题默认执行。
- 多个 skill 叠加时，执行顺序为：skill-1 → （2/3/4/5/7/8 按需）→ skill-6 兜底。
- skill 内引用的文件路径均从库根出发（`docs/…`）；引用小节名以各文件当前标题为准。

## 维护

- skill 只固化流程与引用点，不复制正文数值；正文数值变动时只需核对引用小节是否仍然存在。
- 新增 skill 前，先用高频问题实测知识库现有回答路径，确认断点真实存在再立项；先行立项未实测的（如 skill-7、skill-8），入库后补实测复核。
