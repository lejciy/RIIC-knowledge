# skill-3 缺员替代与组合降级

> 使用时机：用户抄排班缺关键干员（「没有贝洛内/伺夜/迷迭香/森蚺怎么办」）、box 里某组合缺一环、某干员没精二、问某站第三席带谁。答案分散在注册表、组合深稿、技能等价组、高效率散件、互斥规则五处，漏任何一环都会给出带隐藏冲突的阵容。本 skill 把「定位 → 降级 → 替换 → 复校」固化为必走步骤。

## 执行流程

### 第一步：定位组合与判定完成状态

按 skill-1 消歧后，查 `docs/3-组合库/组合注册表.md` 确认：

- 该干员在组合中的层级（核心/重要/次级/挂件），并**直接按档给处置方向**：
  - **核心**：组合不能使用——直接回答用不了该组合，转向替代组合；
  - **重要**：放弃对应的分支或席位，该位置建议用其他角色代替；
  - **次级/挂件**：影响较小，组合照常运转，视情况补位。
- 按注册表·完成状态口径判定用户处境：**缺核心、暂时无法启动** / **持有可启动、练度不足** / **已成型**。

### 第二步：先查组合自身的降级档

多数组合深稿自带降级路径，直接引用，不自行推演：

- 打开该组合深稿（`docs/3-组合库/跨设施体系/` 或 `单站组合/`），读「启用条件」「建议用法」「效率分档」小节。例：叙拉古缺八幡海铃降为双人 80% 档（订单上限 +2 保留）；伺夜、贝洛内分驻两站各 45%、无上限加成。
- 深稿未写降级档时，查 `docs/3-组合库/组合总览.md` 一览表的一句话提示（如「无戴菲恩 75%」「缺八幡海铃 80%」）。

### 第三步：缺成员按三条路线找替补

按顺序尝试，找到为止：

1. **组内替代**：先读该组合深稿的成员表、分档表与「缺人降级」小节——同组的重要/次级成员与挂件常已写明顶位方式（如自动化组缺森蚺时第三人由冬时顶上，或由自动化·α 持有者异客/掠风替换）；分档表里往往已有替代形态的效率档。
2. **等价替换**：查 `docs/2-干员技能/技能等价组.md`，看缺失干员的核心技能是否有效果逐字相同的其他持有者（同效不同名）；有则整组持有者是候选。
3. **散件替补**：查 `docs/3-组合库/高效率散件.md` 按设施与产物（贸易/赤金/经验/通用/搓玉/办公室/发电站）找同位置散件，附参考效率与练度门槛。

问「第三席带谁」时直接走本步：先看组合深稿·建议用法是否写明第三席取向（如叙拉古第三人在但书、可露希尔中二选一），再查散件表补充。

### 第四步：互斥复校（不得省略）

替换或降级后的新阵容，**只针对本次替代涉及的组合与设施**过一遍 `docs/3-组合库/组合总览.md`·互斥规则——被替换干员的原组合、新进人选的所属组合、受影响的设施，三类对象各查一遍：

- **机制互斥**：同站技能直接冲突（如本次替代涉及特殊订单改写者或归零类时的同站限制）。
- **资源位互斥**：中枢 5 人位、办公室席位、挂件计数位、同一干员身兼两组。

给出的人选若与用户现有阵容冲突，明确指出并给分站/换位方案；与本次替代无关的通用互斥示例不写进回答。

### 第五步：中枢与练度联动

- 替换动到中枢成员时，查 `docs/6-专家经验/中枢席位取舍.md` 复核席位取舍。
- 替换人选需要精二才生效的（如孑），注明练度门槛；精二反而变差的（如卡夫卡），按深稿提示标出。
- 用户自述萌新/box 浅时，参照 `docs/6-专家经验/新手培养.md` 的分设施推荐给够用配置。
- 缺的核心值得为基建练的判断与培养先后，参照 `docs/6-专家经验/练卡取向.md` 的五档名录与玩家类型顺序（取舍流程见 skill-7）。

## 红线

- 只推荐知识库收录的干员与路径；库内查无此人的，直说没有，不编造技能效果。
- 第四步互斥复校在任何替换建议后都必须出现，即使结论是「无冲突」也要说明已检查。

## 输出要求

按用户处境给结论：缺谁 → 组合降到哪一档（效率变化）→ 替补人选（含练度门槛）→ 互斥检查结果。条件分支时分条写清「有 X 时选 A、没有 X 时选 B」。
