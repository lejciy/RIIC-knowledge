# skill-4 组合对比与场景选型

> 使用时机：「可露希尔组和但书组谁收益高」「赤金够/不够时用哪组」「贸易站给谁带队」「A 组合和 B 组合怎么选」。对比的陷阱在于：特殊组合的纸面效率互相不可比，且「按赤金状态切换推荐」是一个知识库已证伪的判断框架。本 skill 固化「取锚点 → 判可比性 → 摊平比较 → 布局前提 → 互斥检查」的顺序。

## 执行流程

### 第一步：取两组合同的档位与锚点

按 skill-1 消歧定位两组合同深稿，取：满配/降级档效率（深稿·效率分档）、日产出锚点（`docs/1-基础设定/资源体系/产出常数表.md`·特殊组合自有锚点，含龙门币与赤金两列）。

### 第二步：判可比性——纸面效率禁止直接比

改写订单类的组合（龙舌兰、但书、可露希尔），纸面效率与实际产出之间隔一层订单乘区，比较必须落到**锚点口径**：实际产出 = 纸面总效率 × 该组合基准产出数值；同纸面效率下直接比锚点行即可（如可露希尔 12000 龙门币＋2000 赤金/日 对比 龙舌兰组 12739.73＋2328.77/日）。锚点未收录的组合之间不做数值对比，只答机制差异。

### 第三步：摊平比较，不随赤金库存翻转

组合之间的比较一律用摊平口径：锚点行的龙门币＋赤金产值合计（赤金列即等效赤金产能口径，见产出常数表·等效效率）就是摊平后的总价值，直接比较。**不得按用户当前赤金库存状态切换推荐**——「赤金紧缺就选自带赤金产能的组合、赤金充裕就选但书」一类翻转说法，与无人机投向的已证误区同构（`docs/7-基建布局/无人机使用.md`·常见误区：比较本身已把补赤金的成本摊入，排序不随库存状态翻转）。

赤金供需失衡属于**产线配平问题**，用布局层手段解决（`docs/7-基建布局/布局选择.md`·产能倾向、`docs/1-基础设定/资源体系/基建生产关系.md`·赤金供需平衡：调赤金站配比、补赤金体系、无人机配平），不用换带队组合来迁就。组合选择的真实条件是：box 持有、互斥关系、站级适配（但书吃低级站、龙舌兰组与合成玉订单刚需三级站）。用户没说赤金状态时可以教判断方法（卖出 ≈ 龙门币÷500 对比当日赤金产量），但结论不因状态分叉。

### 第四步：布局与场景前提

- 搓玉期、经验向、常驻自足等场景的布局前提查 `docs/7-基建布局/布局选择.md`·按需求推荐；布局电力结构限制组合落位时查 `docs/7-基建布局/布局总表.md`。
- 涉及调整设施等级腾电时，可降级性约束查 `docs/1-基础设定/设施与进驻/罗德岛基建建设.md`·可降级性：功能设施（会客室/加工站/办公室/训练室）不可降级，腾电只能压左侧生产设施与宿舍的等级；站级按排班进驻人数配（几个人上班配几级站）。
- 跨布局比较产出时，价值折算口径引用 `docs/7-基建布局/钱书价值与价值比例.md`（本库口径：改良无人机系数 0.5:0.8:1），不自行设定权重。

### 第五步：互斥与共存检查

同 skill-3 第四步：候选组合与用户现有阵容过 `docs/3-组合库/组合总览.md`·互斥规则；典型如但书+可露希尔不能同贸易站、八幡海铃驻中枢使琴柳感染力失效。

## 红线

- 对比数值只引用锚点行已有的数，禁止把两组合的效率百分数直接相减当结论。
- 禁止按赤金库存状态切换推荐组合（见第三步）；赤金失衡的处方是产线配平，落在布局层。
- 用户条件（布局、box）未知时，结论按条件分支呈现，禁止默认用户处于某一状态。

## 输出要求

一句话结论（摊平口径下选谁）→ 锚点数值对比（两列：龙门币/赤金）→ 组合选择条件（box、互斥、站级适配）→ 赤金供需另走产线配平建议 → 互斥提示。
