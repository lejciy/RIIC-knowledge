# 参考样例（samples）

> 玩家实号数据样例，为排班表审查、组合效率核对、缺员替代等工作提供输入参考。不属于知识语料（`docs/`），仅作数据样例使用。

## 文件

| 文件 | 内容 |
|---|---|
| `排班表-243两班-maa.json` | 可露希尔基建终端导出的 MAA 格式排班方案：243 布局、两班各 720 分钟，含菲亚梅塔换人目标与无人机投向（班次 1 投制造、班次 2 投贸易） |
| `干员练度-box.json` | 干员持有与练度清单 397 条（全部持有）：`id`/`name`/`elite`/`level`/`potential`/`rarity` |

## 使用约定

- 两个文件均为 2026-09-26 入库的一次性快照：原文件名含玩家标识，入库时已脱敏改名，内容未改动。
- 仅作参考输入，不作为知识事实来源；据此推导的结论须注明以本样例为输入。
