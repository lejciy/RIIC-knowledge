> **用途**：从玩家高频提问中抽样 12 题，作为本知识库的问答回归用例——检验 RAG／助手接入后的回答质量，也可用于对比不同检索策略与提示词的效果。
> **抽样原则**：覆盖机制、技能、组合、核算、操作、工具、练卡、搓玉各主题；含单点机制题、多级核算链题、对比选型题（含提问框架需要纠偏的）、缺员替代题、工具 FAQ 与换班操作题。

> **评分要点**：标准答案给出的是**结论与判定路径**，不是唯一措辞。判分看三点——结论是否正确、是否沿正确路径取数、是否遵守数值边界（不现场加总效率、不现算产出、不编库内没有的数值）。

## 样例 1：发电站起什么作用

**题目**：发电站在明日方舟基建里起什么作用？

**作答路径**：skill-1 消歧（无歧义）→ 模块1 路由 → `docs/1-基础设定/设施与进驻/发电站机制.md`。

**标准答案**：

发电站承担两件事：提供电力，以及为无人机充能。

- **提供电力**：支撑其他设施的建造与升级。电力只由发电站提供（Lv.1/2/3 分别 60/130/270），发电站自身不耗电。
- **无人机充能**：基础速度 6 分钟 1 架，只受发电站进驻干员的加成影响；充能无视持有上限持续进行，溢出丢弃。

无人机的用途有两项：加速制造站／贸易站生产（每架减 3 分钟基础耗时，需控制中枢 Lv.3 解锁），以及设施的建造升级与区域清理。

**参考**：《发电站机制》（一句话／设施基础／无人机机制）

## 样例 2：心情耗尽继续上班的损失

**题目**：干员心情耗尽（红脸、注意力涣散）后继续排班上班，有什么实际损失？

**作答路径**：skill-1 → 模块1 → `docs/1-基础设定/设施与进驻/心情与宿舍.md`（心情基础规则）。

**标准答案**：

心情耗尽后技能和加成基本失效，但人还会占据工位。

- 心情归零即**注意力涣散**：后勤技能与进驻加成在内的大部分效果失效——贸易／制造的进驻效率、发电站的充能加成等一并失去；
- 干员**仍占进驻位**：位置被占着、效果大打折扣，等同于低效干员顶岗。

所以排班要靠班次轮换在心情耗尽前把人换下休息，而不是让红脸干员硬上班。

**参考**：《心情与宿舍》·心情基础规则

## 样例 4：阶段技能叠加还是最高

**题目**：干员精 0 / 精 1 / 精 2 三个阶段的基建技能是全部叠加生效，还是只生效最高阶段？

**作答路径**：skill-1 → 模块2 → `docs/2-干员技能/技能-*.md` 快照头部（练度门槛／提升 vs 解锁）。

**标准答案**：

两种都有，按「解锁」和「提升」区分：

- **提升**：达到练度后**替换或增强**前一技能，同一条技能链只生效最新版（如温蒂精二「仿生海龙」是提升，不是新增第三个技能）；
- **解锁**：达到练度**新增**一条技能，旧技能保留、多条并存同时生效（如巫恋精二「低语」是解锁，与她精零技能并存）。

每条技能以快照里的解锁／替换字段为准，不能按星级一概而论。常见规律：一、二星 30 级解锁，三、四星通常精一档，五、六星通常精二档。

**参考**：《技能-\*.md》快照头部（练度门槛／提升 vs 解锁）

## 样例 5：月产折抽核算链

**题目**：每天 240 自然理智，加上月卡和理智药，一个月大概能搓出多少合成玉、折合多少抽？

**作答路径**：skill-2 产出核算链（逐级留痕）→ `docs/1-基础设定/资源体系/基建生产关系.md` ＋ `docs/1-基础设定/资源体系/产出常数表.md` ＋ `docs/6-专家经验/搓玉.md`。

**标准答案**：

零氪约 **7500 玉/月（约 12.5 抽）**，小月卡约 **1 万玉/月（约 16.7 抽）**。

拆开看：

- 换算：600 合成玉＝1 抽；一抽的生产成本为 60 源石碎片＝120 固源岩＋9.6 万龙门币；
- 月产量级：零氪约 7500 玉/月、小月卡约 1 万/月；有月卡每日总理智约 320（240 自然＋80 月卡），折约 66 块固源岩/日，全力刷土日约 330 玉；
- 长期搓玉的全程量级为年 80~100 抽（小月卡口径）；
- 提醒：基建搓玉产能可以超过每日刷土供给，长期瓶颈在固源岩获取，不在产线。

**参考**：《基建生产关系》·理智与刷土；《产出常数表》·跨资源换算；《搓玉》

## 样例 6：可露希尔组 vs 但书组 vs 巫恋龙舌兰组

**题目**：赤金充足和赤金紧缺两种情况下，可露希尔组与但书组、巫恋龙舌兰组相比，分别谁收益更高？

**作答路径**：skill-4 组合对比 → `docs/1-基础设定/资源体系/产出常数表.md`（特殊组合自有锚点）＋ `docs/7-基建布局/无人机使用.md`（常见误区）。

**标准答案**：

但书、龙舌兰组、可露希尔的共性是**都改变订单类型**——改写之后纸面效率失去可比性，实际收益取决于各自的**产出基准与队友效率**。摊平口径下的锚点对比如下（每 1.0 总效率·24h）：

| 组合 | 龙门币/日 | 赤金/日 |
|---|---|---|
| 但书精二·三级站单走 | 15929.2 | 0 |
| 龙舌兰组满配 | 12739.73 | 2328.77 |
| 可露希尔（队友双人 90% 档） | 12000 | 2000 |

表内龙舌兰组满配为巫恋精二＋龙舌兰精二＋裁缝·β；但书吃低级站——Lv.1 单走 20000、Lv.2 约 1.81 倍率，均无赤金产出。

两点提醒：

- 「赤金充足／紧缺分别谁高」这个前提不成立：摊平比较时赤金产值已计入总价值，排序不随库存状态翻转；
- 实际选组看 box 持有、同站互斥（可露希尔与但书、龙舌兰同站互斥，只能分站带队）、站级适配（但书吃低级站，龙舌兰组与合成玉订单刚需三级站，可露希尔任意站基准一致）；赤金供需失衡走产线配平解决，不用换带队组合迁就。

**参考**：《产出常数表》·特殊组合自有锚点与等效效率；《无人机使用》·常见误区

## 样例 7：缺关键干员的下位替代

**题目**：抄高配排班表时缺关键干员（贝洛内、伺夜、迷迭香、森蚺等）怎么办？常见的下位替代有哪些？

**作答路径**：skill-3 缺员替代（第一步档次判定 → 缺人降级节 → 替补三路线 → 互斥复校）→ `docs/3-组合库/` 各深稿。

**标准答案**：

缺关键干员时，先看他在这套组合里是什么档次，处置完全不同：

- **核心**：组合用不了，直接换别的组合；
- **重要**：放弃对应的分支或席位，位置用其他角色顶替；
- **次级／挂件**：影响小，组合照常运转。

这四人分别是：

- **迷迭香**（感知信息组·核心）：体系直接关闭，制造／贸易产能转用其他组合；
- **森蚺**（自动化组·重要）：放弃中枢森蚺分支，改走三发电基本形态；制造第三人由**冬时**顶上，或由**异客、掠风**替换；
- **贝洛内**（叙拉古·重要）：不是核心——放弃这一席，伺夜照常运转，空位从**高效率散件**的贸易表择优补位；
- **伺夜**（叙拉古·核心）：「叙拉古人」活动赠送、常驻可获取，基本不会真缺。

换人后注意互斥关系——比如可露希尔和但书不能同站，这一点不因降级改变。

**参考**：《感知信息组》《自动化组》·缺人降级；《叙拉古》·启用条件；《高效率散件》

## 样例 8：中枢和宿舍的效率加成怎么参与计算

**题目**：中枢和宿舍提供的效率加成是怎么参与计算的？

**作答路径**：skill-1 → 模块1 → `docs/1-基础设定/结算规则/buff叠加模型.md` ＋ `docs/1-基础设定/资源体系/产出常数表.md` ＋ `docs/1-基础设定/设施与进驻/心情与宿舍.md`。

**标准答案**：

中枢的加成直接进效率公式；宿舍不提供效率加成，它管的是心情侧。

- **中枢**：部分中枢技能提供全局效率加成，与设施基础、进驻加成、干员技能同式相加。库内算例：纸面 200% 中，基础与进驻合计 103、干员技能合计 90、中枢光环 7；
- **宿舍**：价值在心情恢复（宿舍等级白字＋氛围绿字），通过补回心情避免涣散，保住各设施的进驻加成与技能效果——决定的是效率能否持续生效，而非效率本身。

**参考**：《buff叠加模型》；《产出常数表》·等效效率；《心情与宿舍》

## 样例 9：必练推荐与理由

**题目**：基建干员有哪些高性价比的必练或优先推荐？巫恋、龙舌兰、但书这类「基建幻神」为什么值得优先精二？

**作答路径**：skill-7 练卡取舍（定身份 → 五档判据）→ `docs/6-专家经验/练卡取向.md`（五档推荐名录）。

**标准答案**：

「必练必拿」档名录如下：

| 干员 | 目标练度 | 基建身份 |
|---|---|---|
| 但书 | 精二 | 全基建核心散件，违约索赔改写订单 |
| 可露希尔 | 精二 | 全基建核心散件，特别订单改写 |
| 巫恋 | 精二 | 龙舌兰组核心 |
| 龙舌兰 | 精二 | 龙舌兰组核心 |

## 样例 10：排班表导入 MAA

**题目**：基建排班工具生成的排班表应该怎么导入 MAA 实现自动换班？具体操作步骤是什么？

**作答路径**：skill-6 使用时机（先查使用问答）→ `docs/4-排班算法/可露希尔基建终端使用问答.md` ＋ `docs/5-换班操作/定时换班.md`。

**标准答案**：

六步：

1. 在排班工具生成排班；
2. 下载或导出 MAA 自定义基建 JSON；
3. 打开 MAA，进入「基建换班」或「自定义基建」；
4. 导入 JSON 文件；
5. 检查基建布局、设施产物、班次时间和干员名单；
6. 确认无误后，再开启 MAA 自动换班任务。

两点注意：

- MAA 不同版本的入口名称可能不同；
- 导入后两种用法：**定时时刻表**（每班附 24h 制执行时刻，到点自动执行，适合 24h 周期）、**班次轮流**（每次执行轮滚到下一班，适合 12/12/12 这类超 24h 周期，应全程交给 MAA）；用 MAA 定时换班不要开启宿舍锁定。

**参考**：《可露希尔基建终端使用问答》·导入步骤；《定时换班》·MAA 执行

## 样例 11：三班倒怎么操作

**题目**：三班倒具体怎么操作？12 小时一换的换班时间点应该怎么安排？

**作答路径**：skill-1 → 模块5 → `docs/5-换班操作/定时换班.md`（操作过程·班制表）＋ `错班轮换.md`。

**标准答案**：

三班倒是错班轮换的经典应用，操作三步：

1. **预设队列**：为每个设施按班次编辑三个队列，同一组合体系内的角色编入**编号相同的队列**——轮滚时各设施同编号队列一起推进，体系同步上下班。例：巫恋、但书、可露希尔三组轮两个贸易站，贸易站 1 三个队列依次为巫恋、巫恋、可露希尔，贸易站 2 对应为但书、可露希尔、但书；三个班次分别是（巫恋＋但书）（巫恋＋可露希尔）（可露希尔＋但书），三人各上两班休一班；
2. **日常执行**：到点把各设施队列按编号轮滚（1→2→3→1 同步推进），换下的干员分批进宿舍休整；
3. **时间安排**：「12 小时一换」即 **12/12/12 班制**——36h 一个周期、平均 12h 一换，做二休一、适配所有布局，是手动玩家最推荐的班制；换班时刻按自己作息固定两个间隔 12h 的时点并全程保持。

其他班制：8/8/8 时间比例与 12/12/12 完全一致、只是周期更短，对暖机组合有损失；12/6/6 主力工时占比更高（工 18 休 6），产出高于 12/12/12。

**参考**：《定时换班》·操作过程与班制表；《错班轮换》·三组三班结构

## 样例 12：存量固源岩短期转化

**题目**：已经囤了几万固源岩，但只想短期转化成合成玉、不想大改基建布局，用什么方式转化最快？

**作答路径**：skill-1 → 模块6／7／3 → `docs/1-基础设定/资源体系/基建生产关系.md` ＋ `docs/7-基建布局/布局选择.md` ＋ `docs/3-组合库/单站组合/泡泡火神组.md` ＋ `docs/3-组合库/高效率散件.md`。

**标准答案**：

转化速度取决于**源石碎片制造与合成玉贸易两条产线的效率**——想尽快转化就把这两条产线提上去，不必大改布局。

- **转化链**：固源岩 → 源石碎片（制造站）→ 合成玉（贸易站「开采协力」，需贸易站 Lv.3）；任一侧吞吐不足，产量就被压在较小的一侧；
- **产线建议**：现有布局内把制造站切源石碎片配方、贸易站切开采协力；1.0 效率的「1 制造＋1 贸易」配成一条 240 玉/日线，存量土充足时产线效率就是转化速度的上限；
- **布局参考**：搓玉期产线分配见《布局选择》·搓玉期（333 搓玉期产线；342 三态切换）；
- **搓玉干员**：值得专门配——现成的成套搓玉用法推荐**泡泡火神组**搓玉档：泡泡＋火神＋褐果精一生产源石碎片，+107%、83 格大仓容兼顾库存、避免满仓停产；碎片站散件人选另见《高效率散件》·制造站·源石碎片节。
