# 但书

## 一句话结论

但书（精2）是全基建核心散件、单走一站的形态：以「合同法＋违约索赔·β」把赤金订单改造为违约订单（+2 赤金 / 报酬 +1000），放大单笔订单价值；站位为但书＋订单效率工具人。不能与可露希尔同站——她的特别订单优先级更高，会抢走违约触发。

## 启用条件

- 但书精2（违约索赔·β；精0 只有 α 档，+1 赤金 / 报酬 +500，差距巨大）。
- 单走形态：但书＋任意高贸易效率工具人，工具人可来自散件或纯贸易效率组合。
- 贸易站等级按布局选择：252、342 布局内优先进入 Lv.2 贸易站；其余布局可进入 Lv.3 贸易站。Lv.2 倍率更高（1.81）但不出 4 赤金订单，Lv.3 为常规选择（1.55）。
- 站内无可露希尔（同站互斥，见「互斥与共存」）。

## 建议用法

- 常规站位：但书＋订单效率工具人进驻同一贸易站，拉高订单效率、缩短订单周期。
- 违约订单机制：合同法——下笔赤金订单交付数 <4 即视为违约；违约索赔 α +1 赤金 / 报酬 +500，β +2 赤金 / 报酬 +1000（报酬与赤金数同步增加）。
- 特殊订单联动边界：佩佩、可露希尔、U-Official 的特殊订单「不视作违约订单」，不与合同法/违约索赔联动。机制细节与特殊订单优先级见 [[贸易站机制]]·特殊订单。
- 但书不产出赤金（违约订单改造的是龙门币订单），赤金吞吐需另行配平（见 [[基建生产关系]]·赤金供需平衡）。
- 特殊用法「跑单」——但书、龙舌兰的技能在订单刷新瞬间触发，据此可以只吃触发不吃占位：
  - 操作：订单刷新前，在 Lv.1/Lv.2 贸易站放入但书，或在 Lv.3 贸易站放入龙舌兰＋但书；订单刷新后撤出，换上纯高效率角色。
  - 收益：每一笔订单都拿到特殊订单加成，同时享受订单收益乘区和高贸易效率加成。
  - 产出锚点：龙舌兰＋但书三级站跑单、龙舌兰＋但书＋巫恋三人站的基准产出见 [[产出常数表]]·特殊组合自有锚点。

## 缺人降级

- 缺但书精2 → 退到精0 α 档（+1 赤金 / 报酬 +500），等效 1.276，收益明显缩水；追求收益时建议培养但书至精2。
- 缺订单效率工具人 → 组合仍可运行，订单周期拉长，单位时间收益下降。

## 互斥与共存

- 但书 × 可露希尔：同站互斥——可露希尔的特别订单优先级更高，抢走违约订单触发，只能分站带队（对照见 [[可露希尔特别订单]]）。
- 但书 × 佩佩 / U-Official：同站互斥（特殊订单改写通则）——改写层（佩佩＞可露希尔＞U-Official）优先级均高于违约订单，且三者均「不视作违约订单」；改写者之间同站时一份订单只取优先级最高的一种、其余空转。通则全文与优先级全表见 [[贸易站机制]]·特殊订单。
- 但书 × 龙舌兰组：可同站共存——巫恋＋龙舌兰＋但书同处一站时，巫恋提供效率，龙舌兰技能作用于 4 赤金订单，但书技能作用于 2、3 赤金订单，分工不冲突；双贸易站布局下也可分站各带。
- 但书 × 感知信息组 / 格拉斯哥帮组 / 喀兰贸易组 / 叙拉古等常规效率体系，以及任意纯贸易效率角色：均可搭配使用。

## 边界与误区

- 但书是全基建核心散件，不与任何纯效率角色绑定成固定组合；精二但书是基建优先养成目标之一（养成口径见 [[新手培养]]）。
- 但书不产出赤金：违约订单改造的是龙门币订单，赤金供需需另行配平。
