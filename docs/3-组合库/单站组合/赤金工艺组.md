# 赤金工艺组

## 一句话结论

赤金工艺组（又称苍苔组、金属工艺、贵金属工艺）是单站赤金组合：苍苔精二以「金属工艺·α」+30% 与「打工心得」（站内每个金属工艺类技能为自身再 +5%）带队，同站凑满 3 个金属工艺类技能时苍苔 +45%，常见三人组技能效率合计 +110%～+116%。

## 启用条件

- 苍苔精二：「打工心得」在精二解锁，精零苍苔只有金属工艺·α 的 +30%，无协作放大，组合按精二口径启用。
- 苍苔之外站内至少再有一名金属工艺持有者：同站两人时苍苔 +40%，三人 +45%，苍苔独站只有 +35%。
- 金属工艺·α 与金属工艺·β 都计入「打工心得」，每名干员只计一次。
- 本组只做赤金配方：金属工艺类技能不加工作战记录。

## 建议用法

- 人选范围按技能名判定：技能名含「金属工艺」的干员都可进站计数，当前持有者为苍苔、引星棘刺、砾、斑点、夜烟、温米。
- 常见站位：苍苔＋砾＋引星棘刺（两座贸易站布局 +116%）。引星棘刺未精二时只有 α 档 +30%，与斑点、夜烟同档，三者可互换；夜烟无需练度，是零成本替补。
- 引星棘刺的赤金效率随布局贸易站数量变化：「原质塑金副产物」（精二解锁）为当前制造站贵金属配方每个贸易站 +3%，两座贸易站的布局（如 243）为 +36%、一座（如 153）为 +33%，报告与排班按实际贸易站数取值，不写固定值。
- 苍苔是赠送干员，通过「曲谱—夏日律动—火山旅梦」活动获取，无抽取门槛。

## 互斥与共存

- 赤金工艺组 × 自动化组：同站互斥（归零通则，见 [[自动化组]]·互斥与共存）。

## 数值锚点

- 满档苍苔 +45%＝金属工艺·α 30%＋3 个金属工艺类技能 ×5%（含自身）；常见三人组 +116%（苍苔＋砾＋引星棘刺，两座贸易站）至 +110%（苍苔＋砾＋斑点）。
- 引星棘刺每个贸易站 +3%：两座贸易站 +36%、一座 +33%、三座 +39%，随布局线性变化。

## 边界与误区

- 引星棘刺的「原质塑金副产物」按基建内贸易站数量计数，与按同站技能计数的「打工心得」互不影响，两项加成同时生效。
- 入站资格只看技能名，与干员稀有度和阵营无关：任何金属工艺·α/β 持有者进站即计数。
