# 莱茵科技

## 一句话结论

莱茵科技是单站通用制造组合：多萝西（精二）以「莱茵科技·β」+25% 与「源石技艺理论应用」（站内每个莱茵科技类技能为自身再 +5%）带队，淬羽赫默（γ +30%）与任意莱茵科技·β 持有者为搭档，三人组技能效率合计 +95%。

## 启用条件

- 使用条件是多萝西精二：「莱茵科技·β」在精二解锁，精零的多萝西只有「源石技艺理论应用」、自身无底数，组合按精二口径启用。
- 站内至少 2 个莱茵科技类技能（含多萝西自带）才有协作增量，站内技能越多，「源石技艺理论应用」的放大越高。

## 建议用法

- 三人组：多萝西＋淬羽赫默＋娜斯提，第三席也可换成任意莱茵科技·β 持有者（溯光星源、精二星源/赫默/白面鸮）。
- 双人组：多萝西＋淬羽赫默，或多萝西＋娜斯提。
- 娜斯提另有「造价高昂」按基建内莱茵生命人数给贵金属配方叠加（阵营侧站位与计数见 [[莱茵生命阵营]]），与多萝西组队时技能侧与阵营侧收益同时生效。

## 缺人降级

- 缺淬羽赫默 → 双人组多萝西＋娜斯提（+60%），或第三席由 β/α 持有者补位（+85%~+95%）。
- 缺多萝西 → 无「源石技艺理论应用」放大，淬羽赫默＋娜斯提＋β 第三人合计 +80%，按普通制造散件站衡量。

## 互斥与共存

- 莱茵科技 × 自动化组：同站互斥（归零通则，见 [[自动化组]]·互斥与共存）。

## 数值锚点

- 满配三人组：多萝西 40%（β 25%＋3 个莱茵科技类技能 ×5%）＋淬羽赫默 30%＋β 第三人 25% ＝ +95%；技能数值真源见 [技能-制造站](../../2-干员技能/技能-制造站.md)。
- 娜斯提阵营计数叠满时三人组 +110%（计数口径见 [[莱茵生命阵营]]）。

## 边界与误区

- 「源石技艺理论应用」只放大多萝西自身的生产力，同站其他成员只吃自己的固定加成；计数对象是站内莱茵科技类技能（α/β/γ，每名持有者各计一次），「勘探背包」「造价高昂」等非莱茵科技类技能不计数。
- 莱茵科技技能成员与莱茵生命阵营成员是两个集合：淬羽赫默、溯光星源持有技能而不属阵营；阵营侧增益（造价高昂、生态科主任）归 [[莱茵生命阵营]]，两个系统独立成立、可单独使用。
