# 高效率散件

> 体系核心干员和单站组合占满站位后，剩余空位用散件填充。本文按设施分类给出散件的人选、目标练度、效率数值、成立条件与组合身份；条件不满足时按实际条件重新判断，不把理论上限当固定值。

## 使用口径

- 单走可用：允许依赖宿舍等级、会客室等级、同站工作人数、贸易站数量、基建设施等级等通用环境条件，个别条目带干员条件，在条件列注明。
- 筛选参考线：贸易站订单获取效率 35%，制造站生产力（赤金／经验／通用／源石）35%，办公室联络速度 45%；发电站按 20% 充能档列举。
- 允许暖机：进驻后随时间爬升或需长班次的技能按终值收录，条件列注明。
- 订单上限、仓库容量、心情效果不计入效率，心情代价单列。
- 组合收益不写成散件效率；同一干员已有可启动的组合身份时，优先按组合身份理解其价值。
