# 歧义·组合别名（一意映射）

组合别名只做一意映射：每个俗称指向唯一的规范组合。别名的唯一真源是各组合深稿 front matter `aliases`，本页为全库汇总查表。

撞名消歧的可用线索是**问法**：同一俗称兼为技能类名、官方术语或干员名时，问技能/名单/干员查模块2（[技能-贸易站](../../2-干员技能/技能-贸易站.md)、[技能-制造站](../../2-干员技能/技能-制造站.md)、[类别](../../2-干员技能/类别.md)），问配队指本页对应组合；无法判断时反问。干员名本身的简称与合称歧义归 [歧义-简称合称](歧义-简称合称.md)，子串同名对归 [歧义-子串对](歧义-子串对.md)。
