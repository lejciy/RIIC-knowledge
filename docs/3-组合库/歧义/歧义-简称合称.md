# 歧义·简称与合称（人工维护）

**硬规则**：用户输入恰好等于某个短名／俗称时，不许静默挑一个。静默选错不会有任何报错，但数值会直接答错。

消歧的可用线索是**设施**：如果两人的基建技能落在不同设施，而用户已经点明了设施（「贸易站放谁」「发电站用谁」），就按设施判断并在回答里说明你按哪个理解的；设施重叠或用户没点明的，直接反问。

子串关系的同名对（如「临光 ⊂ 耀骑士临光」）由脚本自动生成，见 [歧义-子串对](歧义-子串对.md)；本文件只收录查表才能得到的简称、合称与官方同名组。

## 简称与合称

不是子串关系，推不出来，只能查表。

- **推王** → 推进之王（宿舍）
  - 本体推进之王的俗称，无歧义。体系名「格拉斯哥帮组」是整体，不要拆开解析。

- **维娜 / 异格推王** → 维娜·维多利亚（贸易站）
  - 简称与异格俗称，均指推进之王的异格维娜·维多利亚，无歧义

- **德狼** → 德克萨斯（贸易站）、拉普兰德（贸易站）
  - 合称

- **德狗** → 德克萨斯（贸易站）
  - 简称，与「德狼」单双字并行，均指德克萨斯

- **拉狗** → 拉普兰德（贸易站）
  - 简称

- **dj** → 涤火杰西卡（控制中枢、贸易站）
  - 简称（「涤杰」拼音首字母），指异格干员涤火杰西卡；本体杰西卡（制造站、会客室）是另一名干员，子串同名对见 [歧义-子串对](歧义-子串对.md)

- **能蕾** → 能天使（贸易站）、蕾缪安（贸易站）
  - 合称

- **银崖** → 银灰（贸易站）、崖心（贸易站、宿舍）
  - 合称

- **孑拉德** → 孑（贸易站）、拉普兰德（贸易站）、德克萨斯（贸易站）
  - 精 0 孑路线

- **龙门中枢组** → 斩业星熊（控制中枢）、诗怀雅（控制中枢、训练室）
  - 合称，控制中枢双人组

- **菲亚 / 肥鸭 / 007 / 毁灭凤凰人** → 菲亚梅塔（宿舍）
  - 简称与俗称，均无歧义；「007」兼指用她换心情支撑干员永续在岗的排班用法（机制见 [菲亚梅塔](../../2-干员技能/释义/菲亚梅塔.md)）

## 官方术语表也把这些视为同一组

游戏自己就把下列名字定义成「包含多个干员」的组，说明这种歧义是游戏层面的，不是用户口误（成员全集见 [类别](../../2-干员技能/类别.md)）：

- **能天使**：新约能天使、能天使
- **嘉维尔**：百炼嘉维尔、嘉维尔
