# 组合库（模块3）

职责：定义和描述干员之间在基建场景下的组合方案——组合建议、替代关系、效率表现、组合原理。单组合知识的真源在各组合深稿，[组合注册表](组合注册表.md) 提供全库词表与定义总表，导航入口是 [组合总览](组合总览.md)。

|---|---|---|
| `组合注册表.md` | 全库词表＋组合定义总表（别名/层/产物/成员层级） | — |

## 收录边界

本库只陈述制造、贸易或跨设施使用的组合：只有真正形成组合（成员之间存在结构化联动或体系依赖）的方案才在这里落地。宿舍、会客室、训练室等位置可能作为组合的挂件或计数位被占用，本库不为这些位置单独建组合；凡未在组合中明确提及的位置与人选，由散件自由搭配使用，走模块2 的技能分片查询，生产类空位的散件人选另见[高效率散件](高效率散件.md)。

## 分层判据

按**设施跨度**分层：「去掉中枢和跨设施资源后，这个组合还成立吗？」成立 → `单站组合/`；不成立 → `跨设施体系/`。

## 引用规则

- 组合文档通过干员/技能名引用 `2-干员技能/` 快照，不重复描述技能运作原理。
- 新组合先落深稿，再同步注册表总表。
