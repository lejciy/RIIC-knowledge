# 怪猎中枢

## 一句话结论

怪猎中枢（又称怪猎组、怪猎小队）是跨设施组合：火龙S黑角＋麒麟R夜刀驻控制中枢产出 12 木天蓼，附带全贸易站订单效率 +7%／全制造站生产力 +2% 光环；泰拉大陆调查团驻贸易站消费，41% 订单获取效率＋订单上限 +2。

## 启用条件

三名成员缺一即关：

- 火龙S黑角精 2＋麒麟R夜刀精 2 同时进驻控制中枢。两人的精 2 光环均以「与怪物猎人小队干员进驻控制中枢一起工作」为生效条件，单人进驻时光环全灭。
- 泰拉大陆调查团与中枢二人同班在岗，进驻贸易站（技能初始解锁）或制造站（技能需等级 30）。生产与消费必须同班：调查团不在岗时木天蓼无消费方，产出空转。

## 建议用法

站位与班次：火龙S黑角＋麒麟R夜刀进驻控制中枢（占 2 席），泰拉大陆调查团进驻贸易站；三人同上同下，整组连续在岗时长按麒麟R夜刀的心情预算确定（见本节心情代价）。

消费端默认贸易站：泰拉大陆调查团贸易站技能「可爱的艾露猫」按每 1 木天蓼 +3% 订单获取效率折算，12 木天蓼合计 41%；制造站技能「可靠的随从们」每 1 木天蓼仅 +1% 生产力（合计 17%），技能原文见 [技能-贸易站](../../2-干员技能/技能-贸易站.md) 与 [技能-制造站](../../2-干员技能/技能-制造站.md)。除当班阵容确实缺制造端外，调查团固定放贸易站。

特殊用法——与精 0 孑同站：调查团自带订单上限 +2，直接抬高精 0 孑「摊贩经济」（订单数与上限每差 1 笔订单获取效率 +4%）的收益空间；同时孑保持精 0 可规避「市井之道」的反噬——精 1 及以上的孑会把站内他人每 10% 订单获取效率折成订单上限 −1，调查团的 41% 意味着 −4 上限，与「摊贩经济」依赖缺口的方向相反。精 0 孑与精 1 孑的取舍见 [[喀兰贸易组]]·边界与误区。

心情代价：麒麟R夜刀「耐力回复」使自身中枢心情消耗 +0.5/h，是全组唯一的额外心情代价；满编中枢吃满全局减免 −0.25 后净耗 1.25/h（基础消耗档与减免口径见 [[心情与宿舍]]、[[控制中枢机制]]）。火龙S黑角与泰拉大陆调查团无额外消耗。排班时夜刀优先安排恢复班，整组班次长度以夜刀心情不触底为准。

## 数值锚点

- 木天蓼池 12 点：麒麟R夜刀「耐力回复」+8，火龙S黑角「团队合作」+2×2（中枢内怪物猎人小队干员为黑角、夜刀两人）；木天蓼为全局资源，生产侧口径见 [[控制中枢机制]]。
- 贸易站消费 41%＝基础 5%＋3%×12；制造站消费 17%＝基础 5%＋1%×12。
- 麒麟R夜刀满编中枢净心情消耗 1.25/h＝基础 1＋「耐力回复」0.5−中枢全局减免 0.25。
- 效率到产出的折算基准归 [[产出常数表]]。

## 边界与误区

- 调查团不在岗（未持有或不同班）时怪猎中枢不开：木天蓼无消费方，火龙S黑角＋麒麟R夜刀只剩互相绑定的 +7%／+2% 光环。同样的光环数值可由无条件光环干员提供——贸易 +7%：明椒「朝气蓬勃」、诗怀雅「大小姐」、阿米娅「合作协议」（均精 0 解锁）；制造 +2%：结城理「领袖魅力」（精 0 解锁）、凯尔希与 Mon3tr「最高权限」（精 2 解锁）——一般不必为光环单独保留黑角＋夜刀。调查团在岗时，木天蓼生产、消费与光环同时成立，怪猎中枢占用中枢 2 席的价值由此成立。
- 调查团 41% 是其站内自身技能结算，火龙S黑角 +7% 是作用于全部贸易站的全局光环，两者口径不同，计入同一座贸易站时分开相加。
- 别名「怪猎小队」指本组合；游戏内技能判定术语「怪物猎人小队」指火龙S黑角、麒麟R夜刀、泰拉大陆调查团三名干员的集合。怪猎二期干员（焰狐龙梓兰、雷狼龙S空爆）属 [[泡影国狩猎小队]]，与木天蓼的生产消费无关。
