# 自动化组

## 一句话结论

自动化组（又称「自动化」「清流自动化」）是制造站电站计数体系：温蒂「仿生海龙」按有效发电站数放大（每站 +15%），承曦格雷伊与森蚺提供虚拟电站，清流按贸易站数加赤金。2 贸易 3 发电的 243 布局满配 140%，2 发电中枢森蚺分支最高 165%（342），清流解绑的通用制造分支 130%，是制造站最强单房体系。

## 启用条件

- 温蒂必须精2（仿生海龙）；没有温蒂精2 → 不建议启用。
- 携带清流时仅生产赤金；经验需求走清流解绑的通用制造分支。

## 建议用法

- 基本形态：温蒂与第三人同驻一座制造站，承曦格雷伊驻发电站提供虚拟电站 +1；森蚺按发电台数选择进制造站还是进控制中枢。
- 制造森蚺（3 发电布局 243/333/153）：森蚺进站作第三人（自动化·β 每站 +10%），本人不在中枢。
- 中枢森蚺（2 发电布局 252/342）：森蚺进驻控制中枢，红脸 0 心情的 Lancet-2 进驻发电站——「我寻思能行」（+2，只认进驻、涣散仍满足）与「晨曦」（+1，涣散作业平台视为未进驻、不阻断）同时生效，合计 +3 虚拟电站；此时森蚺本人不能再任制造第三人。制造站按等级区分上班人数：3 级站 3 人（温蒂＋清流＋冬时），2 级站 2 人（温蒂＋清流）。
- Lancet-2 必须全程保持 0 心情红脸，两个电站技能才同时在线；下班后塞进加工站等非宿舍位置，避免进宿舍回心情打破该用法。
- 清流解绑的通用制造分支：第三人换冬时（温蒂＋森蚺＋冬时），产出改为通用制造、可生产赤金，清流解绑另作他用；单贸易站153布局清流只剩 20%，低于冬时 30%，此时该分支效率反超清流分支。

## 缺人降级

- **缺森蚺（重要）**：制造第三人由冬时顶上（流程优化：站内每名干员 +10% 含自身、三人站 +30%），分档表「温蒂＋清流＋冬时」各行即此形态；或由自动化·α 持有者[异客、掠风](../../2-干员技能/释义/自动化.md)（均精二解锁）替换第三人，每站 +5%（低于森蚺精二自动化·β 的 +10%）。2 发电布局的中枢森蚺分支（最高 165%）随森蚺缺席放弃，改走 3 发电基本形态。
- **缺温蒂（核心）**：体系无法启动，制造站改用其他组合（赤金线见赤金工艺组、经验线见红云组等）。
- **缺承曦格雷伊**：虚拟电站 +1 消失，温蒂按实际发电站数计数。
- **缺清流**：赤金分支失去贸易站计数加成；冬时所在的通用分支不受影响。

## 互斥与共存

- 归零互斥通则：凡进驻制造站、以常规生产力技能输出的组合，一律与自动化组同站互斥——清零范围、豁免（按设施数量计数的加成、站外终端）与可同站的三类队友见 [自动化](../../2-干员技能/释义/自动化.md)，分站带队即可并行。
- 承曦格雷伊 × 驻发电站的作业平台：同设施互斥——「晨曦」要求其他发电站没有进驻作业平台，与把小车放进发电站的体系（阿兰娜＋温米的机械精通搭配、布丁的中枢超频等）在同一套发电设施内不能同时成立；红脸 0 心情的作业平台视为未进驻、不阻断「晨曦」（用法见「建议用法」中枢森蚺分支）。
