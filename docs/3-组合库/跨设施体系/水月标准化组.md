# 水月标准化组

## 一句话结论

水月标准化组（又称水月组、标准化、水月标准化）是以标准化类技能计数为核心的通用制造组合：水月精二带队，单站水月＋任意两名标准化·β 持有者技能效率合计 +90%；黑钢中枢形态（中枢涤火杰西卡＋制造站水月、香草、杰西卡）+100%。

## 启用条件

- 水月精二。
- 黑钢中枢形态需涤火杰西卡精二进驻控制中枢。
- 技能名与解锁档以 [技能-制造站](../../2-干员技能/技能-制造站.md)、[技能-控制中枢](../../2-干员技能/技能-控制中枢.md) 为准。

## 建议用法

### 基础形态：+90%

水月＋任意两名标准化·β 持有者进驻同一制造站。香草、杰西卡初始解锁 β 档、精零即用，是成本最低的搭档；三人合计 +90%。

### 黑钢中枢形态：+100%

制造站固定水月＋香草＋杰西卡，涤火杰西卡进驻控制中枢，三人合计 +100%。赤金出口：精二杏仁进驻任一制造站即 +36% 赤金效率——小奇思 +25%＋挑大梁 +6%（基建内黑钢国际由香草、杰西卡、杏仁恰好凑满 3 名封顶，涤火杰西卡不占该计数）＋中枢涤火杰西卡「老友相聚」对制造站黑钢国际干员 +5%。

### 海沫红松扩展：经验站 +107%

水月＋海沫＋一名红松骑士团干员（灰毫、远牙、野鬃）进驻同一制造站做作战记录，中枢沿用 [[红松林骑士组]] 的焰尾＋薇薇安娜；海沫需精二。原理是海沫「意识兼容」把站内莱茵科技类、红松骑士团类技能也视作标准化类技能：红松骑士团·β 保留自身词条、照常吃焰尾与薇薇安娜的中枢加成，同时计入水月的计数。效率：水月 +40%（β 25%＋3 个标准化类技能 ×5%：自身、海沫、被视作的红松 β）＋海沫 +25%＋红松 +42%（β 25%＋焰尾 10%＋薇薇安娜 7%）＝ +107%。焰尾对赤金配方 −10%，此扩展只做作战记录；另外两名红松骑士团干员可分驻其他制造站带队，各 +42%。
