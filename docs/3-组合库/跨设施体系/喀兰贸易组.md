# 喀兰贸易组

## 一句话结论

喀兰贸易组是跨设施贸易组合：灵知精二驻控制中枢压效换订单上限，孑精一＋银灰精二驻三级贸易站，双人合计 85% 订单获取效率、恒定不波动；第三人产龙门币用但书／可露希尔，搓玉用琳琅诗怀雅（满配合计 129%）。订单上限堆得高，基本不用担心爆仓；没有灵知时这套阵容不成立。

## 启用条件

- 灵知精二进驻控制中枢，是整组成立的前提——没有灵知压低效率，精一孑会按完整的他人效率压缩订单上限，整组收益降低（见「边界与误区」）。
- 孑精一即可，精二与否不影响使用。
- 银灰精二。
- 贸易站 Lv.3。
- 第三人一名，按要生产的资源选择。

## 建议用法

- 站位：灵知进驻控制中枢；孑、银灰与第三人进驻同一座三级贸易站。
- 第三人按产物选择：
  - 产龙门币：但书或可露希尔二选一（两人同站互斥）。两人负责抬升单笔订单收益，站内效率就是孑银灰双人恒定 85%，可露希尔另带自身 +10%。
  - 搓玉（生产合成玉）：琳琅诗怀雅、崖心、锏、讯使、角峰依次降档。崖心、讯使、角峰、锏都是谢拉格干员，灵知「精密计算」给他们每人 +6 订单上限；琳琅诗怀雅「招商引资」按站内提升的每个订单上限 +4% 效率，同样吃到这份加成。
- 机制依据：灵知的 −15% 在孑读取他人效率之前生效，孑读到的他人效率被压低、压缩掉的订单上限更少；堆高的订单上限又垫高孑「每有 1 笔在站订单 +4%」的结算基数。大库存下订单长期堆满，效率稳定在峰值不再波动（结算次序见 [[buff叠加模型]]）。
- 爆仓优势：整组订单上限累计很高，收菜间隔长也不会满单停产；可露希尔特别订单与合成玉订单是全贸易最容易爆仓的两条生产线，本组在这两条生产线上最不需要担心爆仓（口径见 [[库存与爆仓]]·贸易站）。

## 缺人降级

- 没有灵知精二：本组合无法成立，换用其他贸易组合。灵知为中坚干员、新玩家不易获取时，可退为「散件叠库存」用法——银灰（新手六星可兑换）、崖心（开局赠送）各自单走仍带 +20%/+15% 效率与 +4 上限，再搭配涤火杰西卡（「订单管理·β」：+10% 效率、+4 上限）、瑰盐（精二「订单分发·β」+30% 效率；「钱不我待」按所在站等级每级 +1 上限）等上限散件与普通效率角色组站，搓玉线同样吃得下大库存（取舍取向见 [搓玉](../../6-专家经验/搓玉.md)·生产干员取向）。
- 没有银灰：崖心精二顶替银灰位（+15% 效率、+4 上限，比银灰低 5% 效率），第三人照常选择。
- 没有指定第三人：搓玉线按持有情况在琳琅诗怀雅 → 崖心 → 锏 → 讯使／角峰内顺延；产龙门币时第三人直接用但书或可露希尔。

## 数值锚点

- 孑精一＋银灰双人合计 85% 订单获取效率＋10 订单上限，恒定。
- 搓玉线第三人档：琳琅诗怀雅 129%、崖心 125%、锏 121%、讯使／角峰 117%。
- 精 0 递减档：孑银灰双人峰值 85%，第三人琳琅诗怀雅／锏时峰值 145%，均随订单堆积下滑。

## 边界与误区

- 第三人怎么选，看最终效率。产龙门币时三档排序：精一孑＋银灰＋但书／可露希尔 ＞ 精 0 孑＋银灰＋但书／可露希尔 ＞ 精 0 孑＋银灰＋琳琅诗怀雅／锏。前两档同为孑银灰双人 85%，精一恒定、精 0 随订单堆积递减；末档峰值虽有 145%，同样递减，整体不及前两档。跑单或搓玉时按需另行选择（精 0 孑的同站用法见 [[怪猎中枢]]·与精 0 孑同站变体）。
- 没有灵知时不要用这套阵容：精一孑会按完整的他人效率压缩订单上限，仅银灰 +20% 效率一项就压掉 2 个上限，银灰与灵知堆出的上限空间被压掉大半，整组收益明显降低；把孑停在精 0 规避压缩也不划算，递减档的最终效率更低（见上条）。
- 订单上限是本组的辅助收益：银灰、崖心、灵知提供的上限量不能单独折算成订单获取效率相加。
