# 组合总览

> 命名与成员关系的真源是 [[组合注册表]]。本文只做导航；凡与注册表冲突处以注册表为准。社区俗称作为别名收录在各组合条目（如巫恋组＝龙舌兰组）。

## 分层判据

按**设施跨度**分层，一句话判据：去掉中枢和跨设施资源后组合还成立吗？
- 成立 → 单站组合；不成立 → 跨设施体系。

## 互斥规则

互斥按成因分两类：**机制互斥**为同站或同设施内技能机制直接冲突，分站、分房带队即可并行；**资源位互斥**为共享中枢席位、办公室席位、挂件空位或同一干员，可挤占、非硬互斥。

### 机制互斥

- **但书 + 可露希尔**：不能同贸易站（可露希尔订单抢但书触发）
- **特殊订单改写通则**：改写层（佩佩＞可露希尔＞U-Official）覆盖但书（违约订单）与龙舌兰（投资）——任一改写者与后两者不能同贸易站，改写者之间同站按优先级取一、其余空转；优先级全表见 [贸易站机制](../1-基础设定/设施与进驻/贸易站机制.md)·特殊订单
- **归零通则（自动化组 × 常规生产力组合）**：凡进驻制造站、以常规生产力技能输出的组合不能与归零类同制造站；豁免与可同站队友见 [自动化](../2-干员技能/释义/自动化.md)，分站带队即可并行
- **深海猎人组 + 自动化组**：不能同制造站（清零效果优先生效）
- **深海猎人组 + 槐琥**：不能同制造站（官方标注「集群狩猎」无法与「配合意识」叠加——中枢加成不入槐琥读数，深海猎人又无自身制造技能，同站零转化）
- **承曦格雷伊 + 驻发电站小车体系**：「晨曦」要求其他发电站无作业平台，与阿兰娜（机械精通）、布丁（超频）等把小车驻发电站的体系同设施互斥（红脸 0 心情的作业平台不阻断）

### 资源位互斥

- **中枢 5 人位**：所有需要中枢干员的组合共享 5 个中枢位
- **办公室席位**：
  - 感知信息组 + 人间烟火组：絮雨与桑葚二选一，令/夕心情档二选一（混合用法除外，见感知信息组·建议用法）
  - 感知信息组 + 叙拉古（人力取向）：中枢琴柳＋办公室絮雨（感知取向）与中枢八幡海铃＋办公室高人力干员（人力取向）只能二选一——八幡海铃的 +10% 联络速度计入感染力的 30% 判定、使其失效；制造、贸易与挂件位不受影响，取舍本质是更高的制造&贸易效率与更高的人力（公招刷新）之间
  - 感知信息组 + 凯尔希·思衡托（精英干员挂件）：凯尔希·思衡托进驻期间絮雨无法同驻，感知链降档；迷迭香可兼担两侧
  - 人间烟火组 + 叙拉古（人力取向）：桑葚占用办公室且不提供联络速度，烟火取向与八幡海铃/焰狐龙梓兰联络光环下的公招刷新取向二选一（见人间烟火组·互斥与共存）
- **挂件位**：S.E.E.S.组、莱茵生命阵营、凯尔希·思衡托（精英干员挂件）、鸿雪杜林组（杜林挂件）等计数体系共享基建挂件空位
- **成员重叠**：
  - 能天使组 + 拉特兰：蕾缪安为两组合共同核心，只能进驻一座贸易站
  - 企鹅物流 + 能天使组：能天使为两组合共同成员，能天使组双核具备时优先归能天使组
