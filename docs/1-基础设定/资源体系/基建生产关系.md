# 基建生产关系

> 本文是资源体系的关系层，讲三件事：**效率如何折算成产出、产物之间是什么上下游、两条转化链怎么配平**；三日报表则是读取这一切运转结果的窗口。产出数字以 [[产出常数表]] 为真源，单个设施的机制见 [[制造站机制]] / [[贸易站机制]]，场景取向归模块6。

## 一句话

制造站产出作战记录、赤金、源石碎片，其中赤金与源石碎片要经贸易站转化为龙门币与合成玉；日产出 = 基准产出数值 × 总效率 × 在岗时长占比，制造与贸易两侧的吞吐是否配平，靠三日报表来核对。

## 产物与转化关系

```
制造站（一个站同时只做一种配方）
  ├─ 作战记录 ─────────────→ 直接使用（加 EXP），不进贸易站
  ├─ 赤金 ─────→ 贸易站·龙门商法 → 龙门币（每赤金固定 500）
  │                                     └→ 基建外：养成消耗 / 源石碎片配方投入
  └─ 源石碎片（耗 固源岩×2＋1600 或 装置×1＋1000 龙门币）
        └─────→ 贸易站·开采协力 → 合成玉（2 碎片＝20 玉）→ 抽卡

  （双芯片：1 秒完成，不占排班考虑）
```


| 产物                 | 产线                     | 上游投入                                | 基准产出（1.0 效率·24h）              |
| -------------------- | ------------------------ | --------------------------------------- | -------------------------------------- |
| 经验（作战记录）     | 制造站                   | 无                                      | 8000 点（锚定中级）                    |
| 赤金（中间产物）     | 制造站                   | 无                                      | 20 枚＝1 万价值                        |
| 龙门币               | 贸易站·龙门商法         | 赤金                                    | 10000 / 10141 / 10265（站级 Lv.1/2/3） |
| 源石碎片（中间产物） | 制造站（Lv.3 解锁配方）  | 固源岩×2＋1600 或 装置×1＋1000 龙门币 | 24 枚                                  |
| 合成玉               | 贸易站·开采协力（Lv.3） | 源石碎片                                | 240 玉（耗 24 碎片）                   |

- 基准产出数值、特殊组合的自有锚点与无人机折算，真源都在 [[产出常数表]]；配方与订单明细见 [[制造站机制]]·配方一览、[[贸易站机制]]·谈判策略。
- **龙门币是唯一「产出回流为原料」的节点**——源石碎片的配方要消耗龙门币，等于把贸易侧的产出重新投回制造侧。

读表时最典型的错误，是把「贵金属价值 45 000」和「龙门币 64 100」相加去凑总产能。这两个数是**上下游**，一个是投入、一个是产出，相加等于把同一批赤金算了两遍。

## 从效率到产出

产出总公式如下（效率的构成与叠加次序见 [[buff叠加模型]] 及各设施机制篇）：

```
产出/日 = 基准产出数值 × 总效率 × 在岗时长占比（/24h）
```

- **总效率** ＝ 站基础 1.0 ＋ 满员基础加成（每名非涣散干员 +1%）＋ 干员技能 ＋ 中枢光环（如阿米娅 7%）等。
- **实体产出与无人机的额外产出分开计算、再相加**：每 N 架无人机/日折合 N÷480 的等效效率（[[发电站机制]]·产出折算），报表口径也就是「一日生产 ＋ 无人机收益」。以 400 架无人机为例，折合 400÷480 ≈ 0.83 效率，约合 6.6k 经验 / 8.3k 赤金 / 8.5k 龙门币订单。
- **龙舌兰、但书、可露希尔一类组合走额外乘区**：按（基础＋干员效率）× 特殊基准产出计算，必须用组合自己的锚点，不能拿普通线的数值替代（[[产出常数表]]·特殊组合自有锚点）。

公式也可以倒过来用，从报表日产反推平均效率（估算口径，引用时需注明；两换/三换这类等长班型可直接平均）：

```
平均总效率 ≈ 报表日产 ÷ 基准产出数值 ÷ 站数
例：3.3w 经验 ÷ 0.8w ÷ 2 站 = 2.06 → 减基础 1.03，干员平均 ≈ 1.03
```

班次不等长时，则按在岗时长加权：Σ(基础效率＋干员效率) × 工作时长/24h × 基准产出 = 总收益。

## 三日报表：口径与读法

入口与字段清单见 [[罗德岛基建建设]]·三日报表（控制中枢→基建副手页，前 3 天，每日 4:00 至次日 3:59 结算）。报表记录的是**实际运转结果**：漏收菜、缺料空转、爆仓停产都会把数字压低；每日 4 点结算也带来天然波动，因此**判读要看三日平均水平**。

### 简报字段属于哪一侧

简报里的各字段，可以按下表归到制造或贸易一侧：


| 简报字段                           | 属于       | 含义                              |
| ---------------------------------- | ---------- | --------------------------------- |
| 总计制造了价值 EXP**N** 的作战记录 | **制造侧** | 当日经验产量                      |
| 总计制造了价值**N** 的贵金属       | **制造侧** | 当日赤金产量（按每赤金 500 折算） |
| 贸易站 · 龙门币**N**              | **贸易侧** | 当日卖出赤金换得的龙门币          |
| 贸易站 · 合成玉**N**              | **贸易侧** | 当日卖出源石碎片换得的合成玉      |
| 贵金属订单 / 源石订单成交数        | **贸易侧** | 两种策略各自完成的订单笔数        |

**合成玉为 0 不代表没有产出**，只说明贸易站全部走了龙门商法、没开采协力。

### 收益底限：方法与查表

判读的最后一步，是给「合格线」定位：把所在布局的站数与手头便宜组合的干员效率代入产出总公式，算出来的就是「放对人且正常换班」的收益底限。若报表持续低于底限，说明运转链路出了问题——缺料空转、爆仓停产、漏收菜都会压低数字（原因均为本章开头的机制事实）。

底限数值**随布局与可用组合变化**，本文不固定具体数值：各布局的收益锚点统一查 [[布局总表]]（模块7）。排班误区与自查思路的经验论证归模块6。

### 订单质量指标

- **平均订单质量** = 当日龙门币 ÷ 订单成交数；
- **单位订单耗时** = 24h × 贸易站数 ÷ 订单成交数。

判读时先记住两个数：普通订单单笔上限 2000（4 赤金），Lv.3 常规分布的单笔期望约 1450（2.9 赤金 × 500）。若平均质量持续显著超过期望、逼近 2500 一档，只能来自特殊订单的系统性改造（龙舌兰/但书类，见 [[贸易站机制]]·特殊订单）——这是「跑单」留在报表上的痕迹；单位耗时低于效率所能解释的下限，则说明有人提前囤了单。

## 赤金供需平衡

制造与贸易两侧都具备产能：制造侧的产能是搓出中间产物（赤金、源石碎片）的速率，贸易侧的产能是完成订单的速率。最终产物由两类产能结合而成——龙门币是龙门币订单与赤金的结合，合成玉是开采协力订单与源石碎片的结合；任一侧吞吐不足，最终产量就被压在较小的一侧。就赤金线而言，两侧一旦不匹配就会出问题：

- **赤金产少了** → 贸易站没料可卖，订单空转；
- **赤金产多了** → 制造站仓库溢满，停产。

判断两侧是否匹配只需一步除法（估算口径）：

```
当日卖出赤金数 ≈ 龙门币 ÷ 500，与当日赤金产量对比：
  卖出 > 产出  → 在吃库存，长期不可持续
  卖出 ≈ 产出  → 平衡
  卖出 < 产出  → 贸易站吞吐不足，或赤金站配多了
```

**为什么不能只看报表差额**：用「贸易收入 − 赤金价值」衡量，会系统性低估真实的赤金输入——有三笔赤金从不经过制造侧，也就不会出现在产量里：

1. **外源性赤金**：签到、日常周常、信用/活动/绿票商店、1-7 等基建外来料；除商店与关卡外，每日固定约 10 根（=5000）。
2. **龙舌兰「印钱」**：+500 报酬不消耗赤金，等效凭空新增赤金产能——顶配龙舌兰组下约 +4600/日（素材口径，无人机多配给还会放大）。
3. **可露希尔「特别订单」**：每笔 +200 报酬不消耗赤金（2 赤金固定换 1200，比常规 1000 高 20%），等效凭空新增赤金产能——锚点口径每 1.0 总效率约 +2000/日（[[产出常数表]]·特殊组合自有锚点）。

这类不消耗赤金产能、凭空新增龙门币收益的特殊订单机制，社区统称**「虚空印钞」**：狭义多指龙舌兰「印钱」，广义含可露希尔「特别订单」与佩佩「慧眼独到」（0 赤金固定换 1000，见 [[慧眼独到]]）。核算统一走等效赤金产能口径（[[产出常数表]]·等效效率）。

前两笔合计约 1 万/日，可露希尔组再按锚点约 +2000×总效率计入。判读时据此修正：「贸易 − 赤金×500」的差额在所列输入合计以内算大致平衡；持续超出才是真实赤字，早晚要还。短期吃库存不一定是问题（可能之前攒了货），持续赤字则说明贸易侧强于制造侧，需要调整站位或补赤金体系。

**实操口径（素材）**：给赤金库存定一条警戒线——线以上用无人机加速贸易，线以下加速经验。

## 仓库与订单上限

链上仅有的两块缓冲，是制造站仓库（24/36/54，按产品体积计）与贸易站订单上限（6/8/10）：

- 制造站满仓**停产**，未收取的产品不进道具仓库；贸易站满单则停止获取新订单，交付腾出位置后恢复。
- **缓冲深度决定了两次上线之间的最大间隔**。例：2 级站 36 容量搓源石碎片，12 枚 ×1:00 即满仓停产；3 级站 54 也只到 18 枚。
- 搓玉线两头都快（碎片 1:00/枚、订单 2:00/单且逐单占上限），是最容易爆仓停产的产线；赤金线（1:12/枚）与中级经验（3:00/份）相对耐放。

对策有三条：

1. 组合里编入仓库容量 / 订单上限类技能（家族见 [[制造站机制]]·仓库容量类、[[贸易站机制]]·订单上限类）；
2. 提高上线频率——可以只收菜、不换班；
3. 用长班排班配合收取节奏，避免满仓停产（班型见 [[错班轮换]]）。

## 搓玉换算口径

源石碎片 → 开采协力是合成玉唯一的基建产线。换算常数取自玩家口径：

- **生产 60 源石碎片需消耗 120 固源岩 ＋ 9.6 万龙门币**（装置路线：60 装置＋6 万）；60 碎片经开采协力订单交付得 **600 合成玉（一抽）**。固源岩与龙门币是碎片配方的原料与费用，单向消耗，不可逆向换回。
- 在 1-7 刷取需 4.82 理智/固源岩，而 1 土 = 5 玉，折算下来 **1 理智 ≈ 1.03 合成玉**；白色材料向上合成后可至 1.09 玉/理智。
- 理智与刷土口径：无月卡每日约 240 点自然回复理智，有月卡另有 80 点月卡理智，合计约 320 点；按 1-7 的 4.82 理智/固源岩折算，分别约可获得 50 块与 66 块固源岩。这里的 320 点是有月卡每日总理智，不是自然回复理智。
- 产能侧：1.0 效率的「1 制造（碎片）＋ 1 贸易（开采协力）」恰好配成一条 240 玉/日线；2.0 总效率连续运行 24 小时的单组基准约为 480 玉/日，需要约 96 块固源岩与 7.68 万龙门币——**基建产能可以超过每日刷土供给，长期搓玉的瓶颈在固源岩获取**。
- 月产量量级（素材口径）：零氪约 7500 玉/月，小月卡约 1 万/月；小月卡全力刷土日折约 330 玉（66 块 × 5）。
- 这套换算的前提，是龙门币不依赖理智获取，搓玉本质上是「用理智换合成玉」。是否值得搓、怎么刷归 [[搓玉]]（模块6）；碎片的站位人选见 [[高效率散件]]·源石碎片制造。
- 两条产线的**产能系数**（碎片制造 333.33、开采协力 33.33、全链 1 玉 66.67 经验当量）已在 [[产出常数表]]·跨资源换算注册，推导与在跨布局产值比较中的用法见 [[钱书价值与价值比例]]·合成玉与源石碎片的产能系数。

## 未确认

简报里带时钟图标的那组数（如经验 39h、赤金 42h）语义未定——可能是累计工作时长，也可能是仓库剩余可产时长，对照素材后仍未找到「效率-耗时-产出」之间稳定的换算关系。**不要基于它下结论**，需要时问用户。
