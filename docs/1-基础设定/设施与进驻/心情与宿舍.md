# 心情与宿舍

> 本文只保留机制与数值事实。技能名称与持有干员以模块2 快照 [[技能-宿舍]]、[[技能-控制中枢]] 为真源；班型结构与换班操作见模块5 [[错班轮换]]；场景取向归模块6。

## 一句话

干员心情上限 24 点：工作消耗、宿舍恢复；消耗与恢复速度之比决定最长连续在岗时间与可持续的工休比、班次长度。

## 心情的基础规则

- 上限 **24 点**，实际值带小数，显示时**向下取整**——显示「12」实际为 [12,13)，显示「0」（黄脸）实为 0.x，显示 24 才是满心情。
- 心情归零 → **注意力涣散**：后勤技能与进驻加成在内的大部分效果失效（贸易/制造每人 +1% 的进驻效率、发电站每人 +5%、办公室与会客室的 +5% 非涣散加成等一并失去），干员仍占进驻位（涣散判定见 [[基建总览]]）。
- 部分技能以**当前心情值**为触发条件（令「"山河远阔"」按 >12 / 12 以下切换产出等）。显示取整意味着显示值恰为阈值时无法判定分支——令显示 12 时实际可能仍 >12，要确定处于 12 以下需显示 11。
- 恢复的两条途径：**进驻宿舍**；或留在工作设施内且**回复速度 > 消耗速度**（见「回复高于消耗」）。

## 心情消耗

### 面板公式

设施面板「心情消耗/时」显示为 **1 − X − Y**（默认值 1）：

- **X（灰字）＝设施与人数的基础减免**：Lv.3 制造/贸易按处于工作状态的干员数 1/2/3 名分别 −0/−0.05/−0.1；Lv.2 满员 −0.05；Lv.1 与发电站（单人单站）、办公室、会客室、控制中枢无此项。
- **Y（彩色字）＝干员后勤技能＋中枢群体心情效果之和**（来源分层见下）。
- 计量表口径：面板不计入仅作用于自身的心情效果，实际消耗可能与显示值有差异。

满中枢全局减免（−0.25）下的典型净消耗：

| 设施                               | 设施减免（满员） | 典型净消耗 |
| ---------------------------------- | ---------------- | ---------- |
| Lv.3 制造/贸易                     | −0.10            | **0.65**   |
| Lv.2 制造/贸易                     | −0.05            | 0.70       |
| Lv.1 制造/贸易、发电站、办公室、会客室、控制中枢 | —      | 0.75       |

### 减免来源与叠加

消耗类效果整体**加算**，来源分四层：

| 层           | 机制                                                                                                                               | 代表                                                                                     |
| ------------ | ---------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| 中枢全局     | 每进驻 1 名工作状态中枢干员，全局 −0.05/h（满 5 人 −0.25；作用域含中枢自身，见 [[控制中枢机制]]·基础效果）                          | —                                                                                        |
| 中枢技能     | 对各设施工作干员的「心情恢复」，等效消耗减免；**公事公办（玛恩纳）/ 巴别塔之帜（维什戴尔）/ 孤光共照（重岳）三者互不叠加、取最高**（具名比较见 [[buff叠加模型]]） | 公事公办：发电/办公/会客 +0.1，并使一批中枢内技能（「笑脸类」，名单见 [[技能-控制中枢]]）扩散为对发电/制造/贸易/办公/会客的额外恢复——等效把三类功能设施与 Lv.3 制造贸易的设施减免差补齐；巴别塔之帜：五类设施 +0.1，魔王同中枢再 +0.1 |
| 自身技能     | 直接改自身消耗速率，决定该干员的在岗上限（24 ÷ 净耗）                                                                              | 斥罪「法为正典」+0.5（办公室净耗 1.25 → 上限 19.2h）；泡泡「囤积者」−0.25（Lv.3 制造净耗 0.4 → 60h；再吃中枢 −0.25 → 0.15 → 160h） |
| 设施作用型   | 作用于全站干员；互相可叠加，也可与自身技能叠加                                                                                     | 黍「春雷响，万物长」/ 火哨「暖场」（站内全体 −0.1）；巫恋「低语」（站内全体 +0.25）      |

- 数值示例（泡泡＋黍同站）：黄字 −0.35 = 泡泡自身 −0.25 ＋ 黍 −0.1。
- 观测手段：替换干员前后对比「剩余工作时间倒计时」是否延长（注意倒计时还受效率变动影响，见下文）。

### 消除类的作用域边界

槐琥「团队精神」（制造站）、令「杯莫停」（中枢）等**消除类**技能，抹去的是目标干员**自身技能**带来的心情消耗增减——正负都消：

- 消除：阿罗玛「净味香氛」的 +0.25 会被槐琥消除；火神「工匠精神·β」的 −0.25 同样被消除（减免也会被消掉）。
- 不消除：中枢提供的全局减免，以及他人**作用于设施**的效果——槐琥与黍同站时黍的 −0.1 仍然生效。

### 回复高于消耗

工作设施内若对某干员的回复速度 > 消耗速度，其心情净增长、标识为「休息中/空闲中」（三态定义见 [[基建总览]]）。例：灰烬/战车/闪击/霜华四名彩虹小队进驻中枢，各自「彩虹小队」按中枢内 4 名彩虹成员提供 0.05×4=0.2、合计 +0.8，加中枢满员全局减免等效 +0.25 → 净回复 1.05 > 消耗 1，中枢五人心情不降反升。

### 剩余工作时间倒计时

基建浏览中的「剩余工作时间」= **min(剩余心情可支撑时间, 当前生产任务完成时间, 库存爆仓时间)**：

- 生产因任务完成（典型：搓玉产线）或库存爆仓停止时，心情**不再消耗**。
- 贸易站订单类型多、系统不预测爆仓，倒计时通常即心情时间——可据此反推干员当前心情。
- 倒计时未纳入消耗速度的后续变动，属理论值（贸易站面板口径见 [[贸易站机制]]·心情消耗）。

## 宿舍

### 设施基础

- 全基建宿舍 **4 间**（舱室位于中央区），每间固定 **5 个进驻位**——最多 20 人同时休息；舱室解锁与建材链见 [[罗德岛基建建设]]。
- 宿舍干员自身不消耗心情，恢复类技能常驻生效，无需轮换。
- 氛围值由家具提供、上限由等级决定；氛围另影响每日信用结算与线索搜集速度（→ [[会客室机制]]）。

| 等级 | 升级消耗（无人机/建材数） | 耗电 | 基础恢复（白字） | 氛围上限 |
| ---- | -------------------------- | ---- | ---------------- | -------- |
| Lv.1 | 10 / 1                     | 10   | 1.6              | 1000     |
| Lv.2 | 20 / 3                     | 20   | 1.7              | 2000     |
| Lv.3 | 60 / 3                     | 30   | 1.8              | 3000     |
| Lv.4 | 100 / 4                    | 45   | 1.9              | 4000     |
| Lv.5 | 160 / 8                    | 65   | 2.0              | 5000     |

### 恢复公式

面板「心情恢复/时」= **白字 ＋ 绿字**：

- 白字 = 1.5 + 0.1 × 宿舍等级（由等级唯一决定）；
- 绿字 = 0.0004 × 实际氛围 + 后勤技能加成；
- **面板口径**：计量表不计入非全体恢复的技能（单体、定向等），实际恢复因人而异——同宿舍干员心情不同步即此原因；
- 等级同时决定白字与氛围上限，满氛围下合计为固定值：

| 等级 | 白字 | 满氛围绿字 | 满氛围合计 |
| ---- | ---- | ---------- | ---------- |
| Lv.1 | 1.6  | 0.4        | **2.0**    |
| Lv.2 | 1.7  | 0.8        | 2.5        |
| Lv.3 | 1.8  | 1.2        | 3.0        |
| Lv.4 | 1.9  | 1.6        | 3.5        |
| Lv.5 | 2.0  | 2.0        | **4.0**    |

满级宿舍＋宿管技能后单人恢复约 4~6/h；12 小时休息远超 24 上限——**休息班结束的干员总是满心情**（工休比推导的前提）。

活动室虽有氛围，但不提供心情恢复，室内干员亦不视作进驻基建（→ [[活动室]]）。

### 宿舍技能的作用机制（家族归纳）

> 技能名称、数值与持有干员以模块2 快照 [[技能-宿舍]] 为**真源**（86 技能 / 79 干员）。本节按**作用对象**归纳机制，示例不随版本逐条维护。

不同作用对象的恢复**互相叠加**，同种类型**取最高**：

| 家族           | 机制                                                                                                       | 代表                                                                                                                                  |
| -------------- | ---------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| 群体恢复（群回） | 宿舍内所有干员 +X，同种取最高；部分按外部条件增幅                                                            | 狮心王 / 提灯女神 / 静心仪式·β / 大锅饭·β（+0.2 档）；无词颂歌（每 5 点无声共鸣 +0.01）、调众口（每名岁干员 +0.06，至多 4 名）        |
| 单体恢复（单回） | 对宿舍内**除自身外**心情未满的**某个**干员生效；以快照锁定目标，同一时刻只有一人吃到                           | 慈悲 +0.75；维多利亚文学（琴柳）/ 天启（断罪者）+0.7；对特定阵营再 +0.45 的变体（狩猎好帮手 / 圣城趣事通等）                            |
| 自身恢复（自回） | 只回复自身                                                                                                  | 悲歌 +1、狂热 +0.85、独处 +0.7                                                                                                        |
| 定向/条件恢复  | 作用于满足条件的子集，可与群回叠加                                                                          | 头号陪练（格拉斯哥帮 +0.3）、净化呼吸（心情 <20 额外 +0.1）、芬芳疗养·β（心情 <18 额外 +0.1）                                          |
| 分配型         | 总额固定、由心情未满成员均分，形态随人数在单体/群体间变化                                                    | 小酌怡情（冰酿）：总额 +0.8——1 人各 0.8 / 2 人各 0.4 / 4 人各 0.2                                                                     |

**单体回复的锁定规则**（严格判定与队列保留细节见 [[基建总览]]·单体回复锁定）：

- 单回先入住 → 锁定随后第一位入住者；其他人先入住、单回后入住 → 锁定此前入住者中心情最低者（不选单回宿管）；
- 持有宿舍内最高恢复技能的干员优先充当「宿管」，其效果持续生效、自身最晚被单回回复——琴柳、断罪者因此通常是宿舍内最晚回满的干员。

**中枢技能可加成宿舍**：领袖 / 战纹 / 巡心（宿舍内全体 +0.05，同种取最高）——见 [[控制中枢机制]]·心情恢复类。

### 菲亚梅塔：宿舍恢复的特殊例外

菲亚梅塔不吃**任何来源**的心情回复（宿舍白字/绿字、群体/单体/定向技能一律无效），自身恢复被**替换**为固定 +2/h；满心情（24）时与当前宿舍**前一位进驻**的干员互换心情（「前一位」判定见 [[基建总览]]）。代睡机制与 007 用法见 [[菲亚梅塔]]（模块2 释义专篇）。

### 宿舍作为全局资源生产端

部分宿舍干员不是恢复位而是生产端：爱丽丝（梦境 → 感知信息）、车尔尼（小节 → 感知信息）、塑心（无声共鸣 +1/人）——生产/转化链归组合层，见 [[感知信息组]]。

## 工休比与最长工作时间

### 基本公式

设干员工作消耗 x/h、休息回复 y/h，一管心情 24 点：

- 最长连续在岗 = **24/x**；从零回满 = 24/y；
- 最大工休比 = **y/x**；最大工作时长占比 = **y/(x+y)**；24h 周期内最长在岗 = **24y/(x+y)**。

低于最大占比的任何分配都可持续；休息只需补回「下一班将消耗的心情」，**不必回满 24**。

### 锚点与推论

| 场景（x=0.65：Lv.3 制造/贸易满员＋满中枢） | y   | 工休比 | 工作占比 | 日最长在岗 | 对应班次         |
| ------------------------------------------- | --- | ------ | -------- | ---------- | ---------------- |
| 满级宿舍                                     | 4.0 | 6.15   | 86.0%    | 20.6h      | 20/4（极限 243） |
| 一级宿舍                                     | 2.0 | 3.08   | 75.5%    | 18.1h      | 18/6、16/8（252/342） |
| 一级宿舍＋0.4 群回宿管                      | 2.4 | 3.69   | 78.7%    | 18.9h      | —                |

- 带增耗技能的干员可用时长由自身 x 决定（斥罪 19.2h——单人站轮换班次与人数的核算依据，见 [[错班轮换]]·单设施与多人站班型）。
- 跨设施组合的在岗上限由**组内消耗最快的干员**决定（常见瓶颈：自动化组承曦格雷伊、感知信息组絮雨），整组节奏取决于该干员所在宿舍的回复速度。
- 效率计算通常按满心情、宿舍位足额的简化假设，不逐步模拟心情衰减；实际排班再把心情作为约束条件。

### 班次结构的推导约束

- **宿舍容量是硬约束**：全基建宿舍位 20 个，且宿管/生产端干员常驻占位；243 满配一次在班 ≥29 人（中枢 5＋生产 21＋会客 2＋办公室 1＋训练/加工），主力必须**分批**休息。
- **离散休息的理论上限**：每宿舍一群回＋一单回、各组错峰入住可最大化工作占比，但工作/休息时间完全离散，仅全自动换班可执行（落实形态见模块5 [[动态换班]]）；人类可执行的方案按批次休息＋可接受的时间配置简化（见 [[错班轮换]]）。
- **班次锚点**（结构细节见 [[错班轮换]]）：满级宿舍 20/4 → 三组轮换 **16/4/4**（A+B 16h、A+C 4h、B+C 4h：A/B 各 20/4、C 8/16）；等间隔插入菲亚梅塔代睡可扩展为 **8/8/4/4** 四班（前两班生产组不变、仅换菲亚，机制见 [[菲亚梅塔]]）；二/三电布局放宽后 **12/12/12** 或 **12/6/6** 均可行，后者产出更高。
- **预设换班频次反推**：一天一换（三组按 24h 档轮换 → 每组在岗 48h/休息 24h）要求组内消耗 ≤0.5/h（注意「一天一换」的两种结构不可混用：此处指三组隔天轮换、单班在岗 48h 的形态；24/24 两班做一休一的单班在岗 24h，约束是单班消耗 ≤24 点即 ≤1/h）；否则用 48/24 与 24/24 交替，以极低消耗组合（泡泡＋火神＋贝娜、红云＋刻俄柏＋帕拉斯、古米＋月见夜＋空爆等，组合明细见 [[泡泡火神组]]、[[红云组]]）顶班，使主力组轮流休整——玛恩纳中枢的一天一换/两天一换排班由此构成；换班间隔还需与库存爆仓/收菜节奏兼容。

## 对排班的影响

- 排班瓶颈通常是**宿舍容量**（20 位＋宿管占位）而非恢复速度——满级宿舍恢复远超消耗。
- 增耗干员与跨设施组合的在岗上限按工休比公式逐组核算；组内消耗最快的干员决定整组节奏。
- 换班频次与心情消耗上限互为约束（一天一换 ⇔ 组内 ≤0.5/h）。
