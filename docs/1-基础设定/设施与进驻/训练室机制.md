# 训练室机制

> 本文只保留机制与数值事实。技能名称、数值、持有者与练度门槛的真源是 [[技能-训练室]]（108 技能 / 80 干员）；PRTS 页面的技能持有者列依赖头像图片，纯文本抓取不可读，持有者一律查快照。专精方案编排（先效率后减半的换手、接力人选）的经验稿口径已并入本文·训练速度公式与减半机制两节，自动计算工具的设计素材归模块4。

## 一句话

消耗材料与时间把干员技能从 7 级继续训练到专精三的育成设施；训练位干员被锁定至训练完成，协助位「教官」提供训练速度加成，是该设施唯一的进驻目的。

## 设施基础

- 建造上限 **1** 座；可用舱室 B105、B205、B305；**不可降级**，**训练进行中不可升级**。
- 进驻位 **1+1**：训练位（被专精干员）＋协助位（教官）。
- 建造前置：1 座 Lv.1 办公室（依赖链见 [[罗德岛基建建设]]；第 5~6 间活动室又以本设施为前置，[[活动室]]）。

| 等级 | 进驻上限 | 消耗电力 | 升级消耗（无人机/建材） | 升级或建造条件         | 专精等级上限 |
| ---- | -------- | -------- | ----------------------- | ---------------------- | ------------ |
| Lv.1 | 1+1      | 10       | 10 / 基础加固建材×2    | 建造：1 座 Lv.1 办公室 | 1（专一）    |
| Lv.2 | 1+1      | 30       | 60 / 进阶加固建材×6    | 控制中枢 Lv.3          | 2（专二）    |
| Lv.3 | 1+1      | 60       | 120 / 高级加固建材×10  | 控制中枢 Lv.4          | 3（专三）    |

- **专精等级上限**＝该训练室能训练到的最高专精档：训练专二需 Lv.2、专三需 Lv.3。
- 耗电与降级总表见 [[罗德岛基建建设]]（满级 60 电计入 810 锚点的固定 450 功能设施耗电）。

## 专精训练规则

**前置**：干员技能等级升至 7 级、且干员达到精英 2 阶段。各技能的专精等级**独立**提升（与前 7 级的同步升级不同），单个技能最多至专精三。

**训练计划**：

1. 把待专精干员安排到**训练位**；
2. 在计划表右侧技能列表选择一个技能，查看专精需求——除材料外还需**消耗时间**（材料需求属干员练度域，以游戏内专精需求面板为准，本文不展开）；
3. 确认后训练开始。

- **同时只能执行一个训练计划**；开始后**不可中止**。
- **训练位干员被锁定**：无法被安排至其他房间，直到训练完成；若其所有技能均达专精三，离开训练室后**无法再进驻训练位**。
- 训练期间无法升级训练室（见「设施基础」）。

**协助位**：

- 无训练计划时进驻协助位：**不视为工作状态，无心情消耗**。
- 计划开始后协助位开始基建工作：心情消耗按默认档 **1/h**（训练室无设施档位减免），可被中枢全局减免（满中枢 −0.25 → 净耗 0.75/h，[[心情与宿舍]]）；部分教官技能自带 +1/h 心情代价（如「兴之所至·β」「与人乐」，或协助特定职业训练至特定专精等级时，名单查 [[技能-训练室]]）。
- 协助位**可随时更换**，不影响计划进行；速度按各时段实际驻场者结算（见下）。
- 协助位常驻基础加成：进驻**非注意力涣散**干员时训练速度 **+5%**（涣散判定见 [[基建总览]]）。

## 训练速度公式

> 实际用时 = 基本用时 ÷（100% + Σ教官技能加成 + 5%协助基础 + 5%中枢〔可选〕）

| 专精阶段 | 基本用时 |
| -------- | -------- |
| 专一     | 08:00:00 |
| 专二     | 16:00:00 |
| 专三     | 24:00:00 |

- **教官技能加成（Σ＝该教官同时命中的各条速度技能之和）**：逐条**加算**——同一技能内的条件额外加成与基础档加算（纯烬艾雅法拉「实战技巧：行医」＝医疗 30%、行医分支 30%+45%＝75%）；同一教官多条技能之间也**叠加**（乌尔比安协助近卫干员＝「“问题应当准确”」30%＋「“手段应当有效”」每名深海猎人 +10%、最多 5 名，满编合计 30%+50%＝80%）。
- **协助基础 +5%**：协助位进驻非涣散干员即有，与教官技能无关。
- **中枢 +5%**：烛煌/斩业星熊/阿斯卡纶等进驻控制中枢时生效（**同种效果取最高**，驻场期间对专精全程生效）；家族表见 [[控制中枢机制]]，技能真源 [[技能-控制中枢]]。
- 减半效果生效时：实际用时 = 基本用时 × 50% ÷ 训练速度（进度条从 50% 起跑，见下节）。
- 进度按各时段的实际速度累积：中途更换协助位干员即改变后续速度，换人窗口常用于编排（手法见下节·减半机制）。

**数值示例**（经验稿口径，复算一致）：

- 本系 60% 教官＋协助 5%、无中枢，专三：24 ÷ (1+0.6+0.05) ≈ **14.55h**。
- 艾丽妮（近卫/狙击 30%＋减半）全程协助狙击干员、中枢驻 +5% 光环：专一 8 ÷ 1.4 ≈ 5.71h ≥ 5h 触发减半 → 专二起步 50%（剩余基本 8h），仍 5.71h、再次触发 → 专三起步 50%（剩余基本 12h），换 W「伺机而动」（30%+65%＝95%）：12 ÷ 2.05 ≈ 5.85h。三轮合计 ≈ **17.28h**。

## 减半机制（精神锻炼/言语之义）

持有者：艾丽妮「精神锻炼」、逻各斯「言语之义」（均精 2 解锁，不限职业；二人精零各带双职业 +30% 技能，见 [[技能-训练室]]）。

- **触发**：单次协助一名干员（同一训练计划内）**实际协助时长≥ 5 小时**——判定的是现实协助时长而非基本时间：低效率长计划天然容易触发，高效率短计划可能全程不足 5h。
- **触发可行性判定**：教官接手时的剩余实际时间 ≥ 5h，即 `剩余基本时间 ≥ 5 ×（1 + Σ教官技能加成 + 5%协助基础 + 5%中枢）`。
- **效果**：该干员**下次训练**所需时间 −50%——实际为下次训练开始时**立即完成 50% 进度**；效果记在被训练干员身上，下次训练可由任意教官协助。
- **失效（怕离场）**：从触发到下次训练开启之间（含两轮训练的空窗期），**任意一方离开训练室**（教官撤下或训练位干员撤离）未使用的减半效果即作废，**无例外**——两次训练之间把教官换下同样作废。可更换教官的时点在减半兑现、下次训练开启（进度 50% 起跑）之后——彼时效果已落袋为进度，协助位随时可换、进度不重置。
- **换人与进度**：协助位随时可换，训练进度不重置、速度按各时段结算；但 5h 判定按**同一计划内连续**协助时长计，换人后重新起算。同一计划内先由纯效率教官压缩用时、末段换减半教官干满 5h 同样可触发（换手顺序与用时算例见上节·训练速度公式）。

## 武道机制（思而后行）

- 持有者：左乐（精 2 解锁「思而后行」）。
- 每完整协助完成 1 次专精训练累计武道：至专一 +1、专二 +2、专三 +3，**累计上限 3 点**。
- 达上限后，下一次开始协助**近卫**干员训练专精技能**至 1 级**将**立即完成**，并消耗（清空）已有武道。
- 协助者心情为 0 时，**无法累计也无法消耗**武道。

## 常见边界情况

- **不安排协助位也能训练**：只是没有 +5% 基础加成与教官技能加成。
- **无计划时协助位是免费位**：不视为工作状态、不耗心情、也没有训练加成；但进驻干员仍算「在基建内」，是**挂件类干员**（本身不为目标设施提供效率、只为其他技能提供人数/阵营/计数的干员，定义见 [[组合注册表]]）的免费摆放位——不占生产设施位、零心情成本。
- **训练位锁定波及全基建换班**：含训练位干员的队列无法被快速切换应用、也无法手动应用（[[队列轮换]]·切换限制），长专精期排班需预留该干员缺席；且训练进行期间，**被训练干员与协助位教官都无法被选定进驻**中枢、制造、贸易、发电、会客、办公等其他设施——即使持有对应基建技能，在那些房间的进驻列表里也找不到人（训练位干员须等训练完成，协助位干员须先从协助位撤下才能再安排）。
- **全技能专三的干员无法再上训练位**（离开训练室后）；协助位不受此限。
- **+5% 基础加成要求非涣散**：涣散教官的后勤技能也大部分失效（[[基建总览]]）。
- **训练室等级封顶专精档**：专二/专三分别需要 Lv.2/Lv.3；训练中无法升级，先升满再排长计划。
- **多条速度技能叠加**：同一教官同时命中的多条速度技能之间**加算、不取最高**（乌尔比安对近卫训练＝30%＋每名深海猎人 10%、最多 5 名）；教官技能、协助基础 5%、中枢 5% 三种来源之间同为加算。取最高的只有中枢 +5% 光环家族自身（技能原文声明「同种效果取最高」）。

## 对排班的影响

- 训练室**不产出资源**：不参与 [[基建生产关系]] 吞吐，恒占 1 舱位、满级 60 电（[[布局总表]]）。
- 协助位是育成期的常驻岗位：专三基本 24h，教官选择与减半触发窗口决定换人节奏；教官心情预算按 1/h（吃减免）规划（[[心情与宿舍]]），班型手法归模块5、换手顺序见本文·训练速度公式。
- 训练位干员在计划期间不可用于任何其他设施——育成高峰期等效损失一个进驻位，换班方案需绕开（[[队列轮换]]）。
