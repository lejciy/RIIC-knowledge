# 基建总览

## 设施职责与查询入口
| 条款 | 数值/规则 | 来源小节 |
|---|---|---|
| 发电站 | 无人机充能、供电与发电站进驻规则见 `发电站机制.md` | 设施分工入口 |
| 制造站 | 配方、生产力、仓库容量与制造流程见 `制造站机制.md` | 设施分工入口 |
| 贸易站 | 订单获取、订单上限、订单类型与策略见 `贸易站机制.md` | 设施分工入口 |
| 会客室 | 线索搜集、线索库、传递与交流见 `会客室机制.md` | 设施分工入口 |
| 办公室 | 联络计时、刷新次数与招募位见 `办公室机制.md` | 设施分工入口 |
| 控制中枢 | 全局减免、席位、副手与无人机功能见 `控制中枢机制.md` | 设施分工入口 |
| 宿舍 | 氛围、等级基础恢复与恢复效果范围见 `心情与宿舍.md`；工休计算见 `心情与宿舍.md`（工休计算亦可参照本文干员休整） | 设施分工入口 |
| 进驻心情上限 | 每名干员拥有最高 **24 点**心情 | 进驻状态·标识状态 |
| 进驻标识：未进驻 | 未进驻任何设施，心情不变，无任何标识 | 进驻状态·标识状态 |
| 进驻标识：已进驻 | 进驻任意设施，标舱室位置编号与设施类型；按心情消耗速率分「工作中/空闲中/休息中」三态 | 进驻状态·标识状态 |
| 工作状态定义 | 进驻于**正在工作的工作区设施**即视为「工作状态」——与标识无关，即使标识为「空闲中/休息中」也算工作状态；**注意力涣散干员不算工作状态** | 工作状态 |
| 注意力涣散 | 心情为 0（无论进驻与否）；其后勤技能与基础效率在内的大部分加成失效 | 进驻状态·标识状态 |
| 宿舍锁定/训练中标识 | 宿舍锁定位置→「锁定中」；训练位且正专精→「训练中」（仅队列编辑可见） | 进驻状态·标识状态 |
| 座椅（工位）制 | 进驻按「座位制」，系统将新队列与现有队列**一一匹配**；同一干员仅当**位置相同**才视为保留，否则视为重新进驻（卸下原干员+进驻新干员）；即使两个队列含同一干员，位置不同也视为重新进驻 | 进驻机制 |
| 暖机重置 | 需一定时间达到封顶值（暖机）的技能在**换位时被重置**（因重新进驻） | 进驻机制·衍生情况 |
| 单体回复锁定 | 具有单体心情回复机制的宿舍技能（如波登可），目标优先选**最低心情**干员并锁定至回复满；全新进驻时若被锁定干员排在剩余 4 人之前，则始终锁定 2 号位而非全宿舍最低者；被锁定干员只要未在队列中变更位置，单体回复仍绑定其身上 | 进驻机制·衍生情况 |
| 「前一位进驻」判定 | 菲亚梅塔「患难之交」严格遵循进驻规则选**前一位进驻**的干员——即使该干员是上一次进驻时**保留**的 | 进驻机制·衍生情况 |
| 后勤技能重算时机 | 干员**进驻时**、技能所需**参数发生变化时**（如孑技能依赖的订单数），后勤技能立刻（重新）计算并生效 | 概述 |
| 批量编辑（队列轮换） | 工作区（控制中枢/产出设施/会客室/办公室）可设最多 **3 个预设队列**批量切换；快速切换按「均未处于训练位＞总心情比例最高＞队列序号靠前」选队列 | 进驻方法·批量编辑 |
| 队列切换生效条件 | 当前工作队列存在**注意力涣散**干员、且该设施存在**可用替补队列**（队列干员均未在其他设施进驻）时才切换，两者缺一不可；全局批量应用与单设施切换同一逻辑 | 进驻方法·批量编辑 |
| 训练室/加工站队列豁免 | 两类设施无预设队列，其中干员不适用队列轮换；心情涣散时也无法通过一键休整换下 | 进驻方法·批量编辑 |
| 干员休整 | 宿舍按「未进驻且心情未满」由心情低至高进驻空闲位；优先氛围高＞楼层靠上＞位置靠前 | 进驻方法·批量编辑 |
| 锁定编辑 | 宿舍支持锁定编辑；干员休整仅在非锁定位置进行，锁定空置位同样保持空置；锁定编辑不影响后勤技能生效 | 进驻方法·批量编辑 |

## 队列替换示例

除按位撤出外，所有进驻都是「新队列替换旧队列」。卸下顺序：**旧队列从前到后依次检查 → 位置上干员不同则卸下原干员、进驻新干员**。

例 1（全新队列，E 被保留）：

| 步数 | 0 | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|---|
| 旧 A→E | A | B | C | D | E | — |
| 新 E→I | **E** | F | G | H | I | — |

E 在新旧队列同位置（1 号位），视为保留不重驻；A/B/C/D 依次被卸下，随后 E→F→G→H→I 按位进驻。

例 2（部分保留，B/C 不动）：

| 旧 A→E | A | **B** | **C** | D | E |
|---|---|---|---|---|---|
| 新 F→H | F | **B** | **C** | G | H |

B、C 位置不变视为保留；A/D/E 被替换，进驻顺序 F→G→H。
