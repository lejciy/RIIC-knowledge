# 贸易站机制

> 本文只保留机制与数值事实。体系站位与取向论证见模块3（[[组合总览]]、[[可露希尔特别订单]] 等）与模块6；干员技能原文真源见 `2-干员技能/技能-贸易站.md`。

## 一句话

贸易站产出龙门币与合成玉：进驻干员按谈判策略自动获取订单，交付赤金（或源石碎片）换取报酬；获取效率与订单品质分布由干员技能决定。

## 设施基础

建造上限 5（舱位 B101~B303），可降级直至拆除。

| 等级 | 进驻上限 | 订单上限 | 电力消耗 | 建造/升级条件                                        | 升级消耗（无人机/建材） |
| ---- | -------- | -------- | -------- | ---------------------------------------------------- | ----------------------- |
| Lv.1 | 1        | 6        | 10       | 第 1 座：1 个 Lv.1 制造站；第 2 座起：控制中枢 Lv.3 | 10 / 基础加固建材×1     |
| Lv.2 | 2        | 8        | 30       | 控制中枢 Lv.3                                        | 60 / 进阶加固建材×3     |
| Lv.3 | 3        | 10       | 60       | 控制中枢 Lv.4                                        | 120 / 高级加固建材×5    |

- 建造流程、建材链与用电平衡见 [[罗德岛基建建设]]。
- 贸易站是制造站赤金的下游消费方：制造↔贸易吞吐结构与搓玉全链见 [[基建生产关系]]。

## 效率构成

面板显示「获取订单效率 +X% +Y%」：

- 基准 100%；
- X = 进驻加成：**每名处于工作状态的干员** +1%（满员按站级为 1/2/3 人，即 +1%/+2%/+3%）——注意力涣散的干员不提供（工作状态判定见 [[基建总览]]）；
- Y = 后勤加成：进驻干员的贸易站技能 ＋ 控制中枢对贸易站的全局技能之和（叠加次序与特殊规则见 [[buff叠加模型]]）。

订单实际获取时间 = 基础获取时间 ÷ 获取订单效率。效率只作用于「获取下一笔订单」的计时，不影响已生成的订单（特别独占订单则完全不受效率影响，见「特殊订单」）。

## 心情消耗

面板显示「心情消耗/时 1 + X + Y」（默认值 1）：

- X = 基础心情消耗，按当前**处于工作状态**的干员数：1 名无消耗（且不显示）、2 名 −0.05、3 名 −0.1；
- Y = 干员后勤技能与控制中枢提供的**群体**心情消耗效果之和；
- ※ 计量表不计入非群体（仅作用于自身等）心情消耗的影响，实际值可能与显示有差异；
- 干员信息「倒计时」：按自身当前剩余心情与消耗速度推算进入注意力涣散的理论时间——未纳入消耗速度变动，可能偏离实际。

## 订单运作

### 谈判策略

进驻干员后，按当前设定的谈判策略自动获取订单：

| 策略     | 订单类型             | 贸易站等级 | 订单需求   | 交付报酬    | 基础获取时间 |
| -------- | -------------------- | ---------- | ---------- | ----------- | ------------ |
| 龙门商法 | 贵金属订单（赤金订单） | Lv.1       | 2 赤金     | 1000 龙门币 | 2:24:00      |
|          |                      | Lv.2       | 3 赤金     | 1500 龙门币 | 3:30:00      |
|          |                      | Lv.3       | 4 赤金     | 2000 龙门币 | 4:36:00      |
| 开采协力 | 源石订单             | Lv.3       | 2 源石碎片 | 20 合成玉   | 2:00:00      |

- **每赤金固定 500 龙门币**：高阶策略只放大单笔订单的赤金数与总时长，不改变单位赤金产出比；真正拉开收入差距的是订单品质分布（见下）与技能效率。
- **订单在获取计时时即确定**：修改谈判策略后，从当前订单生成后的**下一次获取**开始生效新策略。
- 源石碎片由制造站生产、曾达 Lv.3 即解锁配方（见 [[制造站机制]]·制造方案），搓玉链换算见 [[基建生产关系]]。

### 订单上限

订单上限 = 站内可同时容纳的未交付订单数（Lv.1/2/3 = 6/8/10）。订单数达到上限后停止获取新订单，交付腾出位置后恢复——上限越高，无人收取时的空转窗口越长。技能可增减订单上限（见「订单上限类」家族）。

### 贵金属订单的生成概率

普通订单的赤金交付数按概率抽取：

| 订单需求 | Lv.1  | Lv.2 | Lv.3 |
| -------- | ----- | ---- | ---- |
| 2 赤金   | 100%  | 60%  | 30%  |
| 3 赤金   | —     | 40%  | 50%  |
| 4 赤金   | —     | —    | 20%  |

Lv.3 常规分布的赤金数学期望为 2.9。

#### 生成概率受技能影响（裁缝类）

部分技能可提升**高品质订单**（赤金交付数较多的订单）的出现概率——家族构成、叠加与暖机口径见 [[裁缝类]]。以下均为 Lv.3 数据（2026-08-06 更新）：

| 订单需求   | 常规 | α 级技能       | β 级技能 |
| ---------- | ---- | -------------- | -------- |
| 2 赤金     | 30%  | 15%            | 5%       |
| 3 赤金     | 50%  | 30%            | 10%      |
| 4 赤金     | 20%  | 55%            | 85%      |
| 数学期望   | 2.9  | 3.4            | 3.8      |

- α 级技能：裁缝·α、手工艺品·α、鉴定师的眼光、懂行、千金的眼光——进驻后**累积工作 3 小时**达到峰值；
- β 级技能：裁缝·β、手工艺品·β、鉴定师的手段——累积工作 **5 小时**达到峰值（持有干员以 [[技能-贸易站]] 为真源）；
- **叠加**：多名裁缝同站逐人叠加（α+α、α+β，确认口径见 [[裁缝类]]）——α+α 峰值观测分布 65%/22%/13%（期望 3.46 赤金）；α+β 观测分布 85%/10%/5%（期望 3.8 赤金），叠加模型暂不确定；
- **累积时间清零**：持有相关技能的干员离开贸易站重新进驻或工位改变时，累积工作时间清空、重新爬升；
- 上述公布数据均为 Lv.3 结果；Lv.2 不出 4 赤金订单、Lv.1 仅 2 赤金订单；
- 理论参考：柏喙后勤技能测算结论、《碎石上千，测试裁缝技能的实际效果》（PRTS 所引）。

### 特殊订单

部分干员技能会把赤金订单改造为**特殊订单**，改变其赤金交付数、交付报酬或订单时长。**一份订单仅可变为一种特殊订单**，多种并存时按优先级取用。目前共 5 种：

| 特殊订单         | 触发技能（干员）               | 优先级 | 属性                                                                                                    |
| ---------------- | ------------------------------ | ------ | ------------------------------------------------------------------------------------------------------- |
| 特别独占订单     | 慧眼独到（佩佩）               | 高     | 0 赤金 → 1000 龙门币；时长固定 4:30:00，**不受任何订单获取效率影响**                                     |
| 可露希尔特别订单 | 特别订单（可露希尔）           | 较高   | 2 赤金 → 1200 龙门币（每赤金 600，比常规高 20%）；时长 2:24:00                                          |
| 尤里卡订单       | 天真的谈判者（U-Official）     | 中     | 赤金交付数固定为 2 → 1000 龙门币；其他属性继承原订单                                                    |
| 违约订单         | 合同法＋违约索赔·α/β（但书）   | 较低   | 合同法：下笔赤金订单交付数 <4 即视为违约；违约索赔 α +1 赤金 / 报酬 +500，β +2 赤金 / 报酬 +1000（报酬与赤金数同步增加）；其他属性继承原订单 |
| 龙舌兰订单       | 投资·α/β（龙舌兰）             | 低     | 下笔赤金订单交付数 >3 时（违约订单不视作赤金订单）：α 报酬 +250、β +500；其他属性继承原订单             |

- 优先级的实际后果：可露希尔特别订单优先于违约订单——两者同站时但书的违约不再触发，只能**分站**带队（组合层分析与分档效率见 [[可露希尔特别订单]]）。
- 佩佩、可露希尔、U-Official 的特殊订单标注「不视作违约订单」：不与但书的合同法/违约索赔联动。

### 无人机加速

无人机可投入贸易站加速订单获取（控制中枢 Lv.3「无人机协助」解锁）——充能、上限与加速公式见 [[发电站机制]]，解锁条件见 [[控制中枢机制]]。

### 效率类（直接或条件提供订单获取效率）

| -------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| 无条件               | 订单分发·α/β、企鹅物流·α/β、物流专家、外贸决议·α/β、交际（另带自身心情 −0.25）                                                            | 进驻即生效的固定 +X%                                                                                           |
| 同站搭档/派系计数    | 恩怨（与拉普兰德同站 +65%，心情 +0.3）、醉翁之意·α/β（与德克萨斯同站心情 −0.1、上限 +2/+4）、同城加急单（每名拉特兰 +15%）、帮派指南针（每名格拉斯哥帮 +20%，与推进之王同站再 +35%） | 读取同站干员的身份/阵营，空位或不在场即失效                                                                     |
| 基建状态读取（跨设施） | 家族经营·α/β（伺夜在基建 +5%/+10%）、对陆接洽代表·α/β（乌尔比安在基建 +5%/+10%）、白手起家·α/β（伊内丝，β 档另含 W；每进驻一间工作场所 +5%）、新城贸易（基础 +25%，会客室每级再 +5%，至多 +40%）、虔诚筹款·α/β（每间宿舍每级 +1%/+2%）、精准排期（基础 +30%，制造站每类进行中配方 +2%）、销路宣发（每条赤金生产线 +5%） | 读取其他设施的进驻状态、等级或产线计数；「赤金生产线」= 每有 1 间制造站生产赤金 +1 条（绮良、鸿雪可额外提供；际崖居民、订单流可视化·α/β 可全局增线；真实/虚拟计数与进驻顺序口径见 [[赤金生产线]]） |
| 环境资源消费         | 「愿者上钩」（每点人间烟火 +1%）、徘徊旋律/怅惘和声（每 4/2 点无声共鸣 +1%）、熟悉的味道（每点魔物料理 +1%）、可爱的艾露猫（每个木天蓼 +3%，另带上限 +2） | 消费跨设施全局资源，资源存量决定收益（资源生产端见 [[控制中枢机制]]·特殊资源生产）                              |
| 读他人数字的派生效率 | 天道酬勤·α/β（站内每 5% 效率再 +5%，上限 25%/35%，实际按 ⌊P/5⌋×5 取整）、勤俭经营·α/β（其他每名工作干员 +10%/+20%）、代为说项（其他每人 +15%）、冠军风采（站内每 5 个上限提升 +25%，至多 +100%）、招商引资（站内每个上限提升 +4%） | 基于同站他人的效率/上限二次计算——结算次序上晚于固定加成，与孑/巫恋的交互见 [[buff叠加模型]]                     |
| 订单差值             | 摊贩经济（当前订单数与上限每差 1 笔 +4%）                                                                                                 | 空仓越多加成越高，在订单上限汇总之后结算                                                                       |
| 归零重构             | 低语（巫恋精 2）：同站其他干员的订单获取效率全部归零，每人为自身 +45%，全体心情消耗 +0.25/h                                                | 重排全站效率分布；归零不影响裁缝与特殊订单的效果（推论见 [[buff叠加模型]]）                                     |

| -------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------- |
| 固定增减       | 喀兰之主 +4（另带 +20% 效率）、谈判 +5、订单管理·α/β +2/+4（各带 +10% 效率）、供应管理/半身人公会代表/大巴扎管理学/使命必达/少当家 +1（各带 +30% 效率）、多面逢源/钱不我待（当前贸易站每级 +1）、队长的自觉 +3、威压 −2 / 不怒自威 −6（订单最少为 1） | 直接增减站内订单上限                                                 |

### 订单类型改变类

裁缝家族改订单分布、特殊订单家族改单笔属性，均已在前文展开（「贵金属订单的生成概率」「特殊订单」两节）。

### 心情消耗类

作用于站内心情而非效率：暖场（站内全体 −0.1/h）、万里传书/跋山涉水（全体 −0.1/h，每 10 点人间烟火再 −0.02/−0.01）等；裁缝类与投资类技能自带自身心情 −0.25。

### 中枢技能对贸易站的全局加成

所有贸易站 +7% 的光环类（同种取最高）、按派系计数的中枢技能（家族认可：每个在贸易站的叙拉古 +5%，巫恋例外见 [[家族认可]]；精密计算：贸易站的谢拉格 −15% 效率/+6 上限；运筹好手：同站格拉斯哥帮 +10%）——明细见 [[控制中枢机制]]·中枢技能分类。

## 对排班的影响

- 裁缝类技能依赖累积在岗时间（α 3 小时/β 5 小时达峰）且离站/换位清零——短班轮换会反复清零爬升，长班更能发挥峰值。
- 特殊订单每次生成只取一种、按优先级——可露希尔与但书同站时后者失效，需分站带队。
- 心情消耗随工作状态人数递减（满员 3 人 −0.1/h）；带自身心情增耗的技能（+0.25~0.3/h）会缩短可连续在岗时长。
- 站位分配与体系取舍（但书单走、巫恋组、叙拉古等竞争贸易位）属组合层与决策层——见 [[组合总览]]（模块3）与模块6。
