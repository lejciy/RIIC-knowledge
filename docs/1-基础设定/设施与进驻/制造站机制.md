# 制造站机制

> 本文只保留机制与数值事实。组合构成与效率论证见 `3-组合库/组合注册表.md`（定义总表）与 `3-组合库/组合总览.md`（导航），散件筛选见 `3-组合库/高效率散件.md`；干员技能原文真源见 `2-干员技能/技能-制造站.md`。

## 一句话

制造站消耗原料生产赤金、作战记录、源石碎片与双芯片；生产力由进驻干员技能叠加，产出存放于各站独立的暂存仓库。

## 设施基础

建造上限 **5** 座（舱位 B101~B303），可降级直至拆除。

| 等级 | 进驻上限 | 仓库容量 | 消耗电力 | 升级消耗（无人机/建材） | 升级或建造条件                     |
| ---- | -------- | -------- | -------- | ----------------------- | ---------------------------------- |
| Lv.1 | 1        | 24       | 10       | 10 / 基础加固建材×1      | 建造：第 1 座需 1 座 Lv.1 发电站；第 2 座起需控制中枢 Lv.3 |
| Lv.2 | 2        | 36       | 30       | 60 / 进阶加固建材×3      | 控制中枢 Lv.3                       |
| Lv.3 | 3        | 54       | 60       | 120 / 高级加固建材×5     | 控制中枢 Lv.4                       |

- 建造流程、建材链与用电平衡见 [[罗德岛基建建设]]。
- 无人机可投入制造站加速生产（需控制中枢 Lv.3「无人机协助」），每架减免 3 分钟基础耗时——充能与加速公式见 [[发电站机制]]。

## 面板效用数据

面板显示四项，默认值口径如下。

### 生产力（1 + X + Y）

- **1** = 基准生产力 100%。
- **X** = 基础加成：每进驻 1 名**非注意力涣散**的干员 +1%（满员按站级为 1/2/3 人，即 +1%/+2%/+3%）。涣散判定见 [[基建总览]]。
- **Y** = 进驻干员后勤技能提供的生产力加成之和。

实际制造用时 = 基础用时 ÷ 生产力。例：赤金基础 1:12，满员无技能时 72 ÷ 1.03 ≈ 69.9 分钟（约 1:10）。

### 心情消耗/时（1 − X − Y）

- **X** = 基础减免：按当前进驻人数，1 人无减免（不显示）、2 人 0.05、3 人 0.1。
- **Y** = 干员后勤技能与控制中枢提供的减免之和。
- 面板数值**不计入自身技能减免**的影响，实际消耗可能有细微偏差。心情恢复见 [[心情与宿舍]]。

### 仓库容量（X/Y）

当前暂存体积 / 容量上限，机制见「仓库与收取」。

### 已节省（00:00:00 起）

- 相对通常生产力，当前制造计划自制定起**累计节省的时间**；可为负数，但显示数值不低于 0。
- 重新设定制造方案时**重置计时器**。

## 制造方案

### 启动与份数

- 指定了制造方案与份数、且进驻了干员后，制造站才开始制造。
- 「1 份」= 方案给出的产品及其数量；份数受原料数量限制，**上限 99 份**。
- 配方表中制造用时均为**无加成的基准值**，实际用时随生产力缩短。

### 配方解锁规则

配方按制造站等级解锁：**基建内存在至少一个达到该等级的制造站，即解锁对应配方，已解锁配方可在任意等级的制造站中使用**。例如基建内有一座制造站达到 Lv.3 解锁源石碎片后，Lv.1~Lv.2 的站也能生产源石碎片。

### 配方一览

| 配方           | 解锁等级 | 原料                                                   | 基础用时 | 产品体积 |
| -------------- | -------- | ------------------------------------------------------ | -------- | -------- |
| 基础作战记录   | Lv.1     | 无                                                     | 0:45:00  | 2        |
| 初级作战记录   | Lv.2     | 无                                                     | 1:20:00  | 3        |
| 中级作战记录   | Lv.3     | 无                                                     | 3:00:00  | 5        |
| 赤金           | Lv.1     | 无                                                     | 1:12:00  | 2        |
| 源石碎片       | Lv.3     | 固源岩×2 + 1600 龙门币，或 装置×1 + 1000 龙门币        | 1:00:00  | 3        |
| 双芯片（8 类） | Lv.3     | 对应芯片组×2 + 芯片助剂×1                              | 0:00:01  | 5        |

- **赤金**是贸易站的消耗原料，产能与吞吐的匹配见 [[基建生产关系]]。
- **源石碎片**消耗龙门币，是合成玉生产的原料；搓玉场景论证归 `6-专家经验/搓玉.md`，本文只固定常数。
- **作战记录**三档产品单份经验值不同：基础 200 / 初级 400 / 中级 1000 点每份，与贸易体系无关，仅产经验卡（1.0 效率日产量锚点见 [[产出常数表]]）。

### 原料预扣

选定含原料的方案时，道具仓库中对应材料按方案所需数目**立即划拨扣除**：

- 每单个产品制造完成前，对应原料均**不视为被消耗**（仅锁定）；
- 下调制造方案数量可**归还**未消耗部分的材料。

### 自动补货

经【游戏设置 → 提醒 → 自动补货】开关控制。开启后，对**无原料消耗**的制造方案，每次收取产品时自动将份数补至最大值；含原料方案（源石碎片、双芯片）不生效。

## 仓库与收取

- 每个制造站的仓库**独立计算**，且并非道具仓库——可理解为制造站的「暂存仓库」。
- **未收取的产品不会进入道具仓库**（不视为持有）；容量按产品体积计（24/36/54），各产品体积见配方表。
- 仓库满且不收取 → 制造站**停产**。
- 干员技能可增减容量上限，或将容量转化为生产力（见下节「仓库容量类」）。

### 结构改写类（归零与放大）

- **归零他人类**：仿生海龙／自动化·α/β／流程优化／科学改造——当前站内**其他干员提供的生产力全部归零**（不含「根据设施数量提供加成」的生产力），自身改按发电站（+15/10/5%）或每名同站干员（流程优化 +10%、仓库 +5）计酬。技能原文注明：此类技能自身提供的生产力不会被同种技能归零。
- **配合意识**：同站其他干员每提供 5% 生产力（不含设施数量加成），额外 +5%，上限 +40%——把他人生产力按 1:1 转化为自身加成的**放大器**，与红云/泡泡这类高加成干员同站时收益最大。
- **意识兼容**：同站莱茵科技类、红松骑士团类技能全部**视作标准化类**——改写技能标签供其他计数技能读取。

## 与贸易站的机制差异

- 产出**确定性**：制造站没有裁缝等效机制——不存在改变产出分布的技能，生产力是唯一变量。
- **仓库容量**是制造站独有维度：满仓停产、容量类技能、容量换生产力都围绕它展开。
- 赤金站与贸易站是**上下游**关系：赤金产少了贸易站缺料空转，产多了满仓停产——匹配判断见 [[基建生产关系]]·赤金供需平衡。

## 常见边界情况

- **配方解锁看基建内等级**：基建内存在至少一个达到该等级的制造站即解锁对应配方，任意等级制造站可用。
- **涣散干员不提供基础 +1%**：注意力涣散的进驻干员不计入基础生产力加成。
- **原料是锁定而非消耗**：预扣材料在产品完成前可随下调份数全额归还。
- **自动补货只对无原料方案生效**：源石碎片、双芯片仍需手动补份数。
- **「已节省」随重设清零**：重新设定制造方案会重置计时器。
- **爬升类随换位重置**：时间爬升/长时条件类技能进度在干员换位时重置（暖机重置），短班轮换会反复清零。

## 对排班的影响

- 时间爬升与长时条件类技能需要**长班**（封顶约 6 小时、「我睡过了」需单次 12 小时），短班轮换收益打折。
- 归零类技能决定**同站结构**：其余席位只需提供心情减负、仓库扩容或全局资源，不必堆生产力；组合论证见各制造组合深稿（[[组合总览]]）。
- 赤金站数量须与贸易站吞吐匹配，产能与收支判断口径见 [[基建生产关系]]。
- 长班需配合收取节奏或容量类技能，避免满仓停产。
- 班型选择见 [[错班轮换]]·单设施与多人站班型。
