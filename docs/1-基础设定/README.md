# 基础设定（模块1）

职责：所有运算和决策的底层物理规则与事实框架——机制公式、设施面板、基础资源链。长期稳定，基建玩法改版时才整体调整。

## 分区导航

| 分区 | 内容 | 判据 |
|---|---|---|
| `设施与进驻/` | 基建总览（进驻状态/座椅制/批量编辑）+ 基建建设（解锁/建材/耗电/改建）+ 信赖值、活动室 + 9 类设施面板与子系统 | 「某类设施的面板或子系统」 |
| `结算规则/` | 跨设施的计算规则（技能结算次序等）；星级技能解锁规则见 `2-干员技能/技能-*.md` 头部投影 | 「跨设施的计算规则」 |
| `资源体系/` | 基建生产关系（产物转化全链、效率到产出换算与倒推、三日报表读法、赤金供需平衡、链上缓冲、搓玉换算）+ 产出常数表（产出总公式、普通产线与特殊组合基准产出锚点、无人机折算）+ 信用、公招与凭证（信用获取与交易所消耗、上限与溢出清空、联络次数与公招标签刷新、招募时长-稀有度、凭证获取比例）+ 库存与爆仓（爆仓时间公式与容满行为）+ 干员升级与模组消耗（升级/模组的钱书消耗逐级累计、六星练度目标钱书比速查） | 「可生产可消耗的东西」 |

引用优先指向具体标题；组合归属与场景取向分别回指模块3和模块6。

中间资源（感知信息/人间烟火/木天蓼/热情值等干员生产的全局资源）不另建汇总页：术语定义见 `2-干员技能/类别.md`，生产端与转化链见本模块各设施机制（中枢、宿舍、办公室），消费端与转化率见模块3 各组合深稿；基础资源的用量常数仍归本模块。
