# 天真的谈判者（U-Official）

## 原文定位

[技能-贸易站](../技能-贸易站.md)（U-Official ☆1 · 辅助节）：

- 「天真的谈判者」（初始解锁）：进驻贸易站时，订单获取效率+10%，当前贸易站赤金订单的赤金交付数必定为2（不视作违约订单）

U-Official 只有这一条贸易站技能，☆1 无精英阶段、没有 α/β 分档（另一条「显眼的调查者」是会客室技能，与贸易无关）。

## 易误读点

1. 实际效果为整笔订单被改写为尤里卡订单：交付数固定 2，报酬固定 1000 龙门币（每赤金 500，常规单价）。
2. 耗时继承原订单：订单刷出时仍按 2/3/4 赤金的质量分布抽取档位，抽中哪档就按哪档的 2:24:00 / 3:30:00 / 4:36:00 计时，订单获取效率照常作用。
3. 分布照旧，「高品质订单」只剩时长意义：抽中 4 赤金档照样等 4:36:00，交付却只有 2 赤金 / 1000——裁缝类「提升高品质订单概率」的技能不提高单笔收益，反而拉长平均耗时。
4. 单笔基准产出被压低：Lv.3 常规分布期望每笔 2.9 赤金 / 1450 龙门币，改写后固定 2 赤金 / 1000（Lv.1 只刷 2 赤金订单，改写前后无差，技能只剩 +10% 效率）。
5. 基准被改写，同样构成独立乘区：订单效率等加成作用在改写后的基准上相乘叠加，同站效率越高，时均收益越高。
6. 改写发生在订单刷新的瞬间——上一笔订单完成、新订单刚刷出时就完成改写，之后不再变更；进驻前已刷出的常规订单保持原样直至交付。

## 特殊执行关系

- 覆盖：尤里卡订单的优先级比违约订单（但书）和龙舌兰订单高，同站时订单会先变成尤里卡订单，合同法、违约索赔、投资都不再生效。佩佩的特别独占订单（[慧眼独到](慧眼独到.md)）与可露希尔特别订单优先级更高——同站时订单先变成他们的特殊订单。
- 「不视作违约订单」是技能原文写明的：不与但书的合同法、违约索赔联动。
- 一份订单只会变成一种特殊订单；设施层特殊订单优先级全表见 [贸易站机制](../../1-基础设定/设施与进驻/贸易站机制.md)·特殊订单。

## 已知边界

- 1000 龙门币、耗时继承原订单与质量分布照旧的口径收录在 [贸易站机制](../../1-基础设定/设施与进驻/贸易站机制.md)·特殊订单；尤里卡订单的等效收益与组合归属归模块3。
