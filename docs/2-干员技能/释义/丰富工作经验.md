# 丰富工作经验（丰川祥子）

## 原文定位

[技能-控制中枢](../技能-控制中枢.md)（丰川祥子 ☆6 · 近卫）：

- **初始解锁**「丰富工作经验」：进驻控制中枢时，所有生产贵金属类配方的制造站生产力+0.5%，每有20点热情值，所有生产贵金属类配方的制造站生产力+0.5%　〔标签：生产力〕
- **精英 2 提升，替换「丰富工作经验」**「丰富工作经验」：进驻控制中枢时，所有生产贵金属类配方的制造站生产力+1%，每有20点热情值，所有生产贵金属类配方的制造站生产力+1%　〔标签：生产力〕
  - 术语「热情值」：可影响丰富工作经验、演技的怪物相关技能 由以下干员的基建技能提供 八幡海铃、三角初华、祐天寺若麦、若叶睦

加成是「固定底数＋热情档位」两段写法，精二把两段数值同步翻倍。祥子的另一条技能「生活的重压」（初始解锁，控制中枢）不提供加成，只在热情值处于 40 点及以上时自身心情每小时消耗+0.05。

## 易误读点

1. 零热情也有底数——进驻控制中枢即固定生效 +0.5%（精二 +1%），「每有20点热情值」只是在底数上叠档，不是从零起步的门槛条件。
2. 只加正在生产赤金的制造站——「贵金属类配方」当前只有赤金一种：判定按各制造站当前配方逐站进行，作战记录、源石碎片、双芯片站一分不加；某站切换配方后按新配方重新判定。
3. 祥子本人不提供热情值——热情值全部来自八幡海铃、三角初华、祐天寺若麦、若叶睦进驻中枢的技能（各提供者数值见 [控制中枢机制](../../1-基础设定/设施与进驻/控制中枢机制.md)·特殊资源生产）；她自己的「生活的重压」方向相反，是热情值达标后的自身心情增耗。

## 特殊执行关系

- 与「所有制造站生产力+x%」全局家族（斩业星熊「共事情谊」、凯尔希／Mon3tr「最高权限」、麒麟R夜刀「以身作则」、布丁「超频」、望「[权变](权变.md)」制造分支）：正常相加——本技能是配方限定类，不参与该家族内部的「同种效果取最高」；同班次同一赤金站内两笔叠加生效，家族内部照旧只取最高一份。
- 与 [自动化](自动化.md) 类（温蒂、森蚺、异客、掠风）及冬时「[流程优化](流程优化.md)」：对驻有这些干员的制造站无效——本技能给到该站的加成属「其他干员提供的生产力」的中枢站外来源，在清零站内归零；「根据设施数量提供加成」的豁免只覆盖清流「再生能源」一类，本技能按热情值计档、不在豁免内。其余赤金站不受影响，照常吃满。

## 已知边界

- 「每有20点」按满档计、零头不折算，为原文直读口径，未单独实测。
- 热情值是否设上限未见官方口径，按实际点数计档。
- 「贵金属类配方」的官方术语未枚举配方清单，当前配方表内仅赤金一种属该类。
