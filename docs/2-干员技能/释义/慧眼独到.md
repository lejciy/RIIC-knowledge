# 慧眼独到（佩佩）

## 原文定位

[技能-贸易站](../技能-贸易站.md)（佩佩 ☆6 · 近卫节），两条贸易站技能各管一件事：

- 「多面逢源」（初始解锁）：进驻贸易站时，当前贸易站每级+1个订单上限
- 「慧眼独到」（精英 2 解锁）：进驻贸易站时，固定获取特别独占订单（不视作违约订单），且该类订单不受任何订单获取效率的影响
- 术语「特别独占订单」：由佩佩提供的特殊贵金属订单，该订单的获取时长固定，收益恒定，所需赤金交付数为0

「慧眼独到」精英 2 解锁——精 0/1 只有「多面逢源」，无订单改造；自身不带效率加成，无 α/β 分档。

## 易误读点

1. 订单类型被直接改变：她进驻的贸易站刷出的每一笔订单都固定为特别独占订单，不再从 2/3/4 赤金订单里抽取，订单质量分布整个失效。
2. 每笔交付 0 赤金、收 1000 龙门币：不交赤金意味着不占上游赤金产能，她是纯龙门币产线。
3. 「不受任何订单获取效率的影响」是绝对的：获取时长锁定 4:30:00，队友与中枢的效率再高也不改变耗时，堆订单效率对她是无效投入。
4. 效率被锁死，无人机是唯一提速手段：每架推进 3 分钟基础耗时，90 架填满一笔 4:30:00（见 [发电站机制](../../1-基础设定/设施与进驻/发电站机制.md)）。
5. 固定获取发生在订单刷新的瞬间——上一笔订单完成、新订单刚刷出时就是特别独占订单，之后不再变更；进驻前已刷出的常规订单保持原样直至交付。

## 特殊执行关系

- 覆盖：特别独占订单优先级最高，高于可露希尔特别订单、尤里卡订单、违约订单（但书）与龙舌兰订单——佩佩同站时这四类技能的订单改造都不再生效；一份订单只会变成一种特殊订单。
- 「不视作违约订单」是技能原文写明的：不与但书的合同法、违约索赔联动。
- 特殊订单优先级全表见 [贸易站机制](../../1-基础设定/设施与进驻/贸易站机制.md)·特殊订单。

## 已知边界

- 1000 龙门币与 4:30:00 时长的口径收录在 [贸易站机制](../../1-基础设定/设施与进驻/贸易站机制.md)·特殊订单；90 架无人机由「每架 3 分钟基础耗时」换算。
