# 菲亚梅塔（自律与患难之交）

## 原文定位

[技能-宿舍](../技能-宿舍.md)（菲亚梅塔 ☆6 · 狙击）：

- **初始解锁**「自律」：进驻宿舍时，自身心情每小时恢复+2，同时无法获得其他来源提供的心情恢复效果
- **初始解锁**「患难之交」：进驻宿舍时，如果自身为满心情，则与当前宿舍前一位进驻的干员互换心情

两条均为初始解锁、不随精英阶段替换。信仰搅拌机「不泯童心」（[技能-会客室](../技能-会客室.md)）读取她是否进驻宿舍，与本页两条技能无执行交集。

## 易误读点

1. 「其他来源」按字面全量执行：宿舍等级白字、氛围绿字、群体/单体/定向恢复技能、中枢宿舍加成一律无效——自身恢复恒为 +2/h，从 0 回满需 12 小时，宿舍等级与氛围对她的恢复速度没有任何影响。
2. 「互换心情」是双方当前值的直接交换：对方瞬间拿到她的满额 24 点、可立刻回岗，她取得对方当前值并从该值起按 2/h 回复。
3. 换错对象是玩家操作失误而非 bug：「前一位进驻」严格按进驻规则判定、上一队列保留的干员也算（[基建总览](../../1-基础设定/设施与进驻/基建总览.md)·「前一位进驻」判定），宿舍留有其他干员时极易把满心情换给非目标——标准操作见「特殊执行关系」。

## 生效条件与作用范围

- 「自律」：恒定 +2/h，从 0 回满需 12 小时；互换取得对方当前值后，回满耗时 =（24 − 该值）÷ 2。
- 「患难之交」：触发条件为自身满心情（24）；作用对象为当前宿舍前一位进驻的干员；效果为双方当前心情值直接互换——等价于把一个满心情即时输送给下班的干员，让其跳过宿舍休息直接继续工作，从而压缩替补干员的在岗时间。她常驻宿舍即可持续运转，自身无需休息班。
- 输送容量恒为 2/h，可视为一个 2/h 的单体回复，供多名干员轮流使用。轮换判据：被支持干员的每小时心情消耗之和 ≤ 2.0 即可实现站内轮流。基准净消耗（满中枢、无额外技能增减，见 [心情与宿舍](../../1-基础设定/设施与进驻/心情与宿舍.md)·心情消耗）：Lv.3 制造/贸易满员 0.65——站内三人 1.95 ≤ 2.0，可实现三人轮流；Lv.2 满员 0.7——两人 1.4 可轮，三人 2.1 超出。
- 高耗干员超出容量即无法永续：歌蕾蒂娅满深海组心情消耗约 3.2/h（[深海猎人组](../../3-组合库/跨设施体系/深海猎人组.md)），单人已大于 2，无法由她支撑 007 永续在岗，必然需要下班休息。
- 代睡对象优先级估算：（被轮换角色效率 − 原有替补角色效率）÷ 每小时心情消耗——商为每消耗她 1 点心情可换取的效率差额，越大越优先。

## 特殊执行关系

- 进驻顺序决定互换对象：执行换心情前先清空当前宿舍，1 号位放被替换心情的干员、2 号位放菲亚梅塔——按位依次进驻使「前一位」恰为目标（进驻按序机制见 [基建总览](../../1-基础设定/设施与进驻/基建总览.md)·队列替换示例）。宿舍残留其他干员时，「前一位」可能是即将出宿舍上班的人，满心情会被换给他们。
- 与宿舍恢复家族：群体/单体/定向恢复对她一律无效，宿管加成同样不作用。
- 「不泯童心」只读进驻状态：菲亚梅塔进驻在宿舍即满足，与她的心情值无关。

## 已知边界

- 互换随进驻与参数变化重算（[基建总览](../../1-基础设定/设施与进驻/基建总览.md)·后勤技能重算时机）；她在宿舍内自然回满的瞬间是否对既有「前一位」自动再触发一次互换，未逐项核实。
- 心情未满期间是否会被宿舍单体恢复技能选中并占用锁定（虽无实际恢复效果），未核实。
