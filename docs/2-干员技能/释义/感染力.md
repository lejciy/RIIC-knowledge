# 感染力（琴柳）

## 原文定位

[技能-控制中枢](../技能-控制中枢.md)（琴柳 ☆6 · 先锋）：

- 「感染力」（精英 2 解锁）：进驻控制中枢时，人力办公室联络速度小于30%时（其中包含基础联络速度5%），则联络速度额外+20%（该加成全局效果唯一，不受其它加成影响）　〔标签：办公室〕

本技能为琴柳独占，作用对象是人力办公室的联络速度。

## 易误读点

1. 「小于 30%」按全部来源相加的合计判定——基础 5%、办公室干员技能、中枢联络加成逐项计入。
2. 与焰狐龙梓兰「办公室年度人物」、八幡海铃「可靠伙伴」同驻中枢时两类加成并存：+10% 照常生效并计入合计，推高判定值。
3. 失效按整条计、核算按 0：中枢 +10% 在位时，办公室干员技能效率达 15% 合计即到 30%（5% + 10% + 15%）；仅琴柳驻中枢时该界为 25%。

## 生效条件与作用范围

- 持有者：琴柳，精英 2 解锁，进驻控制中枢时生效；加成对象是人力办公室的联络速度。
- 判定合计 ＝ 基础联络速度 5%（未涣散基础值）＋ 办公室干员技能联络效率 ＋ 中枢「同种效果取最高」类联络加成（现仅「办公室年度人物」「可靠伙伴」，各 +10%、同驻取最高）。
- 合计 < 30%：联络速度额外 +20%；合计 ≥ 30%：本技能无效果。

## 特殊执行关系

- 晚于中枢取最高类生效：「办公室年度人物」／「可靠伙伴」的 +10% 先计入联络速度、参与阈值判定，感染力随后判定再加成。
- 与取最高类可叠加：+20% 单独成档（全局效果唯一），与「同种效果取最高」的 +10% 相互独立，判定通过时两档相加。

## 已知边界

- 办公室干员心情涣散（基础 5% 缺席）时，阈值是否按较低合计重新判定，未核实。
- 琴柳／八幡海铃／焰狐龙梓兰的席位取舍与办公室散件搭配归模块3 与模块6。
