# 错班轮换

> 本文是错班轮换（又称三班倒、倒班）的**结构支撑页**：轮休的原理与工休比、三组三班的标准结构、时间配置数学与各设施班型。换法选择（两班轮流／错班轮换）、时间配置对照与 MAA 执行见 [[定时换班]]；公式与数值真源见 [[心情与宿舍]]。

## 轮休的原理：周期性与工休比

工作区设施的心情消耗为 0.65～0.75/h（满中枢全局减免后的典型净消耗，分级口径见 [[心情与宿舍]]·心情消耗）。一管 24 点心情可支撑连续在岗 32～36.9 小时，单日内不会涣散；分班的必要性来自周期性——班表循环使用，本周期消耗的心情必须在下次上岗前补回，工作段与休息段共同构成可持续的循环。

宿舍为换下休息的干员提供心情回复，其休息能力决定最大工休比：设工作消耗 x/h、休息回复 y/h，最大工休比 = y/x，24h 周期内最长在岗 = 24y/(x+y)（公式见 [[心情与宿舍]]·工休比）。以 x＝0.65 计：

- 一级宿舍（满氛围 y＝2.0，252/342 二发电布局常见）：工休比约 3.1，日最长在岗约 18.1h；
- 满级宿舍（满氛围 y＝4.0，三发电 243 布局可达）：工休比约 6.2，日最长在岗约 20.6h。

低于最大占比的时间分配均可持续；休息只需补回下一班将消耗的心情，无需回满 24 点。

轮休结构允许把工休比排满：按「24 ÷ 净耗」设定连续在岗时长，下班点可以恰好落在心情清零处（如净耗 0.5/h 的组连上 48h）——极限排班里「部分干员干到心情清零」即这类满负荷轮休的终点表现：清零发生在下班时刻，在岗期间并不涣散，休息段整管回补。

宿舍容量构成另一重约束：全基建宿舍位共 20 个，宿管与宿舍生产端干员常驻占位；243 满配一次在班不少于 29 人（中枢 5、生产 21、会客 2、办公室 1、训练/加工），换下干员须分批休息。两班轮流的一次全换在此容量下无法容纳。

## 三组三班的标准结构

错班轮换将干员分为 A、B 两组主力与 C 组替补：A、B 各为一份完整编制、分掌设施两半，C 以散件填补空位。以 12+6+6 为例：

| 班次 | 时长 | 在岗 | 休息 |
|------|------|------|------|
| 长班 | 12h | A 组 + B 组（全员主力） | C 组 |
| 短班① | 6h | B 组 + C 组 | A 组 |
| 短班② | 6h | C 组 + A 组 | B 组 |

A、B 各工作 18h 休息 6h，C 工作 12h 休息 12h：三组相位错开，任一时刻总有一组心情充足、一组在消耗、一组在宿舍回复，循环得以持续。必须同上同下的干员（如迷迭香与黑键）编入同一组。

### C 组（替补）

替补从剩余干员中按效率择优填位，优先级为贸易、制造、发电；已成体系的房间保留原干员。短班次配置下，高消耗干员（如歌蕾蒂娅，净耗 3.2/h、最长在岗约 7.5h）适合作替补位的效率人选——在岗上限短，与短班节奏吻合。

### 设施两半轮转

长班内 A、B 各负责一半设施，满编运行；两段短班由 C 依次接管 A、B 的半区，主力交替休息。以 12+6+6 为例展开：

- 长班（12h）：A 负责一半设施，B 负责另一半 → 全员主力在岗；
- 短班①（6h）：B 继续负责原半区，C 接管 A 的半区 → A 休息；
- 短班②（6h）：A 返回原半区，C 继续接管 B 的半区 → B 休息。

每个设施三班均在岗，24 小时不间断。

## 时间配置的数学

以下以 x＝0.65（Lv.3 制造/贸易满员＋满中枢减免）为基准，按宿舍等级核算；带增耗技能的干员按自身净耗重算在岗上限。

- **12/6/6**（一级宿舍 y＝2.0）：主力工作 18h 消耗 11.7 点，休息 6h 回复 12 点，恰好覆盖；等分三班（8/8/8）主力每日在岗仅 16h，较 12/6/6 少 2h，不对称配置即以此提高主力工时占比。
- **16/4/4**（满级宿舍 y＝4.0，仅三发电布局可达）：主力工作 20h 消耗 13 点，休息 4h 回复 16 点；需菲亚梅塔一日三次时插入换菲亚与收菜换宿舍一班，成为 8/8/4/4 四班（机制见 [[菲亚梅塔]]）。
- **12/12/12**：每组工作 24h 消耗 15.6 点，休息 12h 在一级宿舍下即可回满，对宿舍回复要求最低，适配所有布局；各组做二休一，无主力替补之分。

各档选择与兼容性见 [[定时换班]]·操作过程；班次锚点总表见 [[心情与宿舍]]·班次结构的推导约束。

## 单站与多人站班型

单人站与多席位设施按同一轮休逻辑收缩班制：轮换单元配置两组人交替，即可维持周期运转。

- **单人站（办公室）**：两人轮换，主力承担两个班次、替补承担一个，三班成周期。
- **单座多席设施（如 153 布局的贸易站，站内三人）**：整设施作为轮换单元，配置主力、替补两组完整编制，同样两班对一班。
- **双人站（会客室）与二级制造站**：三人循环配对 ab / bc / ca，或两对固定搭档 ab / ab / cd，取平均效率高者（人选论证见 `6-专家经验/会客室取向.md`）。

高消耗干员连续两个班次的累计时长超过自身在岗上限时，缩短班次或增加轮换人数——斥罪上限 19.2h，两个 12h 班即超限。

## 中枢的轮换

体系中枢跟随所属体系的角色同时上下班；散件中枢竞争上岗、轮流工作，由接替者持续提供加成。席位分配的取向与竞争细节见 `6-专家经验/中枢席位取舍.md`。
