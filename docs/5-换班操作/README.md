# 换班操作（模块5）

职责：提供换班操作的具体步骤和手法——纯粹的「动作库」，不绑定具体场景或资源倾向。

换班方式分三种，各自独立成文：定时换班、自动轮换、动态换班三篇方式篇均已落地；支撑页为错班轮换（结构）与队列轮换（游戏内动作）。

## 文档导航

- [定时换班](定时换班.md) —— 按固定时刻表整班轮换的换班方式：两班轮流与错班轮换两种换法、班制总述与配置表、MAA 定时执行；三班制、两班倒、手动换班是其包含的具体玩法。
- [自动轮换](自动轮换.md) —— 游戏内置的换班方式：红脸触发、按设施整队替换、干员休整配套；含替补队列配置策略与跨设施体系的错班取舍。
- [动态换班](动态换班.md) —— 面向外部工具 7×24 执行的换班方式：心情阈值触发、按组换人、宿舍满配单回＋群回、N＋1 替班深化、逐笔订单跑单与回满/用尽、黑名单、菲亚 3＋1、条件副表等特殊设置；仅建议搭配 mower 使用。
- [错班轮换](错班轮换.md) —— 错班轮换（又称三班倒、倒班、轮休）的结构支撑页：轮休原理与工休比、三组三班标准结构、时间配置数学、各设施班型与中枢轮换。
- [队列轮换](队列轮换.md) —— 游戏内队列功能的动作篇：手动编辑、队列轮换细则、干员休整、锁定编辑的操作步骤与判定规则。
